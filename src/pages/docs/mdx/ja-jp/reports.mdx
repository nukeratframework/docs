NukeRat では、作戦中に発生したすべての内容のレポートを生成できます。各レポートは PDF（デフォルト）、HTML、JSON でエクスポートできます。利用可能なレポート種別は次のとおりです。

- **Activity（アクティビティ）**: 実行されたターミナルコマンドと取得した資格情報
- **Hosts Report（ホスト）**: 侵害ホストの詳細
- **Indicators of Compromise（IOC）**: 侵害指標の一覧

## アクティビティレポート

アクティビティレポートは、作戦中に何が起きたかの高レベルな概要を提供します。構成は次のとおりです。

| セクション | 説明 |
|---------|-------------|
| 対象範囲（Target scope） | 侵害ホストの一覧 |
| キュー活動（Queue activity） | ターミナルコマンド最大 200 件（時刻、ホスト名、ユーザー、コマンド） |
| 取得資格情報（Captured credentials） | 取得した資格情報最大 200 件 |

アクティビティレポート作成時、**Hide credentials**（資格情報を隠す）を有効にすると、エクスポートで資格情報の内容をマスクできます。

<Callout type="info">
  ヒント: キュー活動の行はターミナルキュー条目由来です。**NukeRat** > **Queue** からキューのコマンドを削除できます。レポート生成前に不要な取得結果を除外するのに便利です。
</Callout>

## ホストレポート

最もシンプルなレポートです。侵害ホストを最大 200 件、1 つの表に一覧します。

- ホスト名
- ユーザー
- オペレーティングシステム
- 内部 IP
- 外部 IP
- NukeRat インプラントの PID

## 侵害指標（IOC）

3 種類のうち最も複雑な IOC レポートです。作戦用に保存された IOC を次のセクションに分けて表示します。

| セクション | 説明 |
|---------|-------------|
| 対象範囲（Target scope） | 侵害ホストの一覧 |
| IP アドレス（IP Addresses） | IP アドレスの一覧 |
| ドメイン（Domains） | ドメインの一覧 |
| ファイル（Files） | コマンド出力から検出されたファイルパスの一覧 |
| ハッシュ（Hashes） | ファイルハッシュの一覧（MD5、SHA1、SHA256） |

NukeRat は IOC データベースを自動で埋めます。ターミナルコマンドは IPv4 アドレス、ドメイン、既知の拡張子向けの正規表現でスキャンされます。ファイルサーバー経由で転送されたファイルにも MD5、SHA1、SHA256 が記録されます。出力を処理する AI モデルなど、裏で動的に走る処理はありません。そのため指標の不一致や単純な取得エラーが起きることもありますが、それほど多くはありません。

<Callout type="info">
    ヒント: 指標取得の問題に対処するため、NukeRat には IOC エディターがあり、取得した指標を確認・削除できます。**NukeRat** > **IOCs** から開けます。
</Callout>

## 制限事項

すべてのレポートは選択したチームサーバー上で生成されます。つまり各レポートは、そのサーバーに接続しているホストに限定されます。

複数のチームサーバーを使っている場合は、サーバーごとにレポートを個別に生成する必要があります。

## フィードバック

レポート生成はまだ実験的な機能です。NukeRat の他機能より変更が頻繁になる可能性があります。主な理由は、オペレーターがレポートに本当に何を求めているかをまだ整理しているためです。

フィードバックや提案がある場合は、GitHub でイシューを開いてください。
