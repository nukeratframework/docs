---
title: ショートカット
---

NukeRat クライアントのキーボードショートカットです。macOS では、これらの組み合わせの **Ctrl** は **⌘**、**Alt** は **⌥** です。ターミナルの文字サイズは、どの環境でも **Ctrl** キーを使います。

## ワークスペース

| ショートカット | 動作 |
| --- | --- |
| Alt+T | ターミナルを開く |
| Alt+F | フォルダエクスプローラーを開く |
| Alt+R | プロセスを開く |
| Alt+S | セッションを開く |
| Alt+A | AI エージェントを開く |
| Alt+K | クレデンシャルを開く |
| Alt+1 … Alt+9 | その番号のワークスペースタブへ切り替える（存在する場合） |
| Ctrl+Shift+W | 新しいワークスペース |
| Shift+Alt+W | 現在のワークスペースを閉じる |
| Ctrl+W | ポインタ下のパネルを閉じる |

## NukeRat メニュー

上部バーのフローティングパネルを開きます。

| ショートカット | 動作 |
| --- | --- |
| Shift+S | Servers |
| Shift+L | Listeners |
| Shift+I | Implants |
| Shift+N | Network |
| Shift+Q | Queue |
| Shift+E | Logs |

## 表示

| ショートカット | 動作 |
| --- | --- |
| F11 | 全画面を切り替える |
| Ctrl++ | 拡大 |
| Ctrl+- | 縮小 |
| Ctrl+0 | ズームをリセット |
| Ctrl+R | ウィンドウを再読み込み |
| Ctrl+Shift+I | 開発者ツールを切り替える |

## アプリケーション

| ショートカット | 動作 |
| --- | --- |
| F1 | ドキュメントを開く |
| Ctrl+Shift+Q | 終了 |
| Escape | 開いているメニューを閉じる。フローティングパネルも閉じる。ただし、その中のダイアログが Escape を使っているときは閉じない |

## ターミナル

ターミナルの上にポインタを置きます。**Ctrl** はどの環境でも **Ctrl** のままです。macOS では、最後の組み合わせの **Alt** は **⌥** です。

| ショートカット | 動作 |
| --- | --- |
| Ctrl+スクロール上 | 文字を大きくする |
| Ctrl+スクロール下 | 文字を小さくする |
| Ctrl+Alt+0 | 文字サイズをリセット |
