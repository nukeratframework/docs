Armory は 543 個のユーティリティ（BOF と .NET 実行ファイル）が揃ったセットで、特定ホスト上ですばやくダウンロードして実行できます。

すべてのユーティリティは公式 NukeRat Armory リポジトリ [**github.com/nukeratframework/armory**](https://github.com/nukeratframework/armory) からダウンロードされます。

プリコンパイル済みが自動でダウンロードされますが、手動ビルドも可能です。その場合:

1. 手動でビルドし、`server/infra/bin/armory/` フォルダに追加する
2. `server/server.conf` の `[server.armory]` 下の `repository` を、独自の GitHub リリースホストを指すように設定する

## コマンド

デフォルトでは NukeRat に Armory バイナリは同梱されません。チームサーバーへインストールするには armory コマンドを使います:

| コマンド | 操作 |
| --- | --- |
| `armory` | 利用可能なユーティリティと短い説明を一覧表示 |
| `armory install all` | 最新リリースバンドルからすべてのユーティリティをダウンロード |
| `armory install &lt;tool&gt;` | 1 つのユーティリティのファイルをダウンロード |
| `armory update` | リポジトリから Armory インデックス（`armory.json`）を更新 |
| `armory update &lt;tool&gt;` | インデックスを更新し、1 つのユーティリティを再ダウンロード |
| `armory remove &lt;tool&gt;` | そのユーティリティのキャッシュファイルを削除 |
| `help &lt;command&gt;` | ユーティリティコマンドのヘルプを表示 |
