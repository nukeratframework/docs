## 概要

NukeRat はレッドチームキャンペーンに特化したポストエクスプロイトフレームワークです。比較すると、Cobalt Strike や Havoc などと同じカテゴリに属します。

## 目的

NukeRat は、レッドチーム担当者が市場の他フレームワークを実際に使い込んだ経験から生まれました。確かに、オープンソースを含めてすでに優れたフレームワークは存在しますが、それぞれに日々の運用を妨げうる限界が残っています。

そのため NukeRat は、現行ツールが残したギャップを埋めつつ、少し異なる感触の機能も提供するように作られました。

すべては *"Make it simple"* を核とするモットーのもと、シンプルさを保ちながら実現されています。

## 機能

NukeRat が提供する主な内容の概要:

- <span className='font-medium'>Armory</span>: 公式 armory リポジトリから引き出して使える、すぐ使えるユーティリティ（BOF および .NET ツール）543 点のコレクション。
- <span className='font-medium'>Evasion:</span> Windows インプラントには、indirect syscalls、sleep masks、文字列難読化など、現代環境向けの必須テクニックが組み込まれています。
- <span className='font-medium'>Cross platform:</span> 標準で Linux と macOS をサポートし、ARM ベースのシステムも含みます。
- <span className='font-medium'>Custom channels:</span> カスタムボディテンプレート付きの HTTP および HTTPS チャネルに加え、Telegram、Dropbox などのサードパーティプラットフォーム向けの完全カスタムチャネル。
- <span className='font-medium'>Client interface:</span> 見落とされがちですが、NukeRat のクライアント UI は長時間の作業でも使いやすく快適になるよう丁寧に設計されています。
- <span className='font-medium'>AI Agent:</span> ローカルモデルやカスタム HTTP プロバイダーを含む AI モデルを、NukeRat に直接統合できます。
