プロセスタブでは、ホスト上で実行中のプロセスをより簡単に分析・監視できます。

上部バーの <span className="inline-flex items-center gap-1 whitespace-nowrap align-middle"><Cpu size={18.5} className="shrink-0 ml-1.5 mr-1.5" /> アイコン</span>から **Processes** タブを開くか、**Tabs** > **Processes** から開けます。

ファイルブラウザと同様、ホストを選択するとクライアントはそのホストのプロセス一覧を要求します。初回読み込み時に応答がプロセスタブに反映されます。

## 仕組み

インプラントは実行中のプロセスを列挙し、結果をクライアントが描画するためのカスタム JSON 形式に変換します。

### Windows

`kernel32.dll`（`CreateToolhelp32Snapshot`、`Process32FirstW`、`Process32NextW`、`OpenProcess`、`QueryFullProcessImageNameW`）と `iphlpapi.dll`（`GetExtendedTcpTable`）を使用します。コアロジックは `implants/windows/stageless/capabilities/process.nim` にあります。

### Linux

`/proc`（`stat`、`status`、`exe`）と `/proc/net/tcp` を読み取ります。コアロジックは `implants/linux/stageless/capabilities/process.nim` にあります。

### MacOS

`macapi` モジュール（`ListProcessIDs`、`ReadProcessStat`、`ReadProcessStatus`、`GetTcpPidMap`）を使用します。コアロジックは `implants/mac/stageless/capabilities/process.go` にあります。
