認証情報タブには主に次の 2 つの目的があります。

1. オペレーター間で認証情報をより簡単に共有する
2. オペレーションレポートに自動で添付する

上部バーの <span className="inline-flex items-center gap-1 whitespace-nowrap align-middle"><KeyRound size={18.5} className="shrink-0 ml-1.5 mr-1.5" /> アイコン</span>から **Credentials** タブを開くか、**Tabs** > **Credentials** から開けます。

<ImageZoom src={credentials} alt="Credentials" className="tutorial_img" />

## 使い方

認証情報タブを使うには、次の手順に従ってください。

  <Steps>
    <Step>
      ### 認証情報を追加
      **Add** ボタンをクリックして新しい認証情報を追加します。
    </Step>
    <Step>
      ### フィールドを入力
      各認証情報はホストとチームサーバーに紐づくため、あらかじめ両方を設定しておく必要があります。
      <ImageZoom src={credentialsAdd} alt="Credentials Add" className="h-[30rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />
    </Step>
    <Step>
      ### 認証情報にアクセス
      追加後、認証情報の行をダブルクリックするとサイドパネルが開き、保存された認証情報テキストを表示できます。
    </Step>
  </Steps>

認証情報一覧ではホストやサーバーの選択は不要です。タブを開くと、クライアントは設定済みのすべてのチームサーバーにすでにリクエストを送信します。
