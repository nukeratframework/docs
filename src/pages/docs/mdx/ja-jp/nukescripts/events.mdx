NukeScript でイベント呼び出しを設定することは、スクリプトを実行するために必須です。そのため、すべてのスクリプトには少なくとも 1 つのイベント呼び出しが必要です。

イベント呼び出しの形式は `event.<name>:my_function()` です。

- `event`: イベント呼び出しの開始を示す予約語
- `<name>`: イベント名
- `my_function()`: イベント発火時に実行される関数

例:

```python
def on_new_host(row):
    cmd(row["tag"], "whoami")

event.new_host:on_new_host()
```

イベントから最初に呼ばれる関数をイベントエントリポイント関数と呼び、特定の構文ルールがあります。

1. エントリポイント呼び出しに引数を渡してはいけません
2. エントリポイント関数はデフォルトでパラメータを 1 つだけ持つべきです（任意の名前でよいが、ここでは `row` をデフォルトとする）
3. すべての `event.<name>:handler()` 行は、他のコードの後、スクリプトの末尾に置く必要があります

以下は構文が誤っている例です。

```python
def on_new_host(row, some_parameter):
    cmd(row["tag"], "whoami")

event.new_host:on_new_host("example")
```

エントリポイント関数の主パラメータには、常にイベント内容を含む辞書が渡されます。これは単にイベントをトリガーしたデータベース行です。

辞書の中身を理解するにはデータベース列レイアウトを知るとよいです。詳細は [データベース列](#データベース列) を参照してください。

## イベント一覧

利用可能なイベント:

| イベント | 説明 | キー |
| --- | --- | --- |
| `new_host` | 初回チェックイン | `tag`, `ip`, `external_ip`, `listener`, `arch`, `os`, `user`, `hostname`, `status`, `delay`, `first_seen`, `last_seen`, `next_checkin`, … |
| `removed_host` | チームサーバーからホスト削除 | `new_host` と同じキー |
| `expired_host` | チェックインウィンドウを逃したホスト | `new_host` と同じキー |
| `new_queue_line` | インプラント実行前にキューに入ったタスク | `tag`, `host`, `type`, `command`, `input`, `parameters`, `is_completed`, `is_ready`, … |
| `implant_error` | キュータスク失敗 | 空でない `error` を含む |
| `task_completed` | エラーなくキュータスク完了 | 完了時 `is_completed`, カスタムメッセージ時 `custom_response` |
| `new_checkin` | 新規チェックイン | `tag`, `host`, `type` |
| `keylogger_update` | キーロガー更新 | `tag`, `content`, `host_tag` |
| `folders_update` | フォルダエクスプローラーの挿入または更新 | `host`, `path`, `type`, `modified`, `size` |
| `process_update` | プロセスツリーの挿入または更新 | `tag`, `host`, `tree` |
| `output_received` | 新規ターミナル出力 | `terminal_id`, `host`, `input`, `output` |
| `credentials_update` | 新規保存資格情報 | `tag`, `name`, `host`, `content` |
| `listeners_update` | 新規リスナー挿入 | `tag`, `type`, `protocol`, `config` |
| `heartbeat_1s` | 1 秒ごとに実行 | |
| `heartbeat_5s` | 5 秒ごとに実行 | |
| `heartbeat_10s` | 10 秒ごとに実行 | |
| `heartbeat_15s` | 15 秒ごとに実行 | |
| `heartbeat_30s` | 30 秒ごとに実行 | |
| `heartbeat_1m` | 1 分ごとに実行 | |
| `heartbeat_5m` | 5 分ごとに実行 | |
| `heartbeat_10m` | 10 分ごとに実行 | |
| `heartbeat_15m` | 15 分ごとに実行 | |
| `heartbeat_20m` | 20 分ごとに実行 | |
| `heartbeat_30m` | 30 分ごとに実行 | |
| `heartbeat_60m` | 60 分ごとに実行 | |
| `heartbeat_2h` | 2 時間ごとに実行 | |
| `heartbeat_12h` | 12 時間ごとに実行 | |
| `heartbeat_1d` | 1 日ごとに実行 | |
| `heartbeat_3d` | 3 日ごとに実行 | |
| `heartbeat_7d` | 7 日ごとに実行 | |
| `heartbeat_15d` | 15 日ごとに実行 | |
| `heartbeat_30d` | 30 日ごとに実行 | |
