title: REST API
---

NukeRat エコシステムには 2 種類の API があります。

1. **インプラント API**: インプラントがチームサーバーとデータを送受信するために使用します。ゼロから独自インプラントを構築する場合に利用します。
2. **チームサーバー API**: NukeRat クライアントがインプラントとチームサーバーを管理するために使用します。動的 AI エージェントや非常に特殊なカスタム連携と統合したい場合に利用します。

## ドキュメント

API の詳細は次を参照してください。

- [インプラント API](/docs/rest-api/implants)
- [チームサーバー API](/docs/rest-api/team-server)
