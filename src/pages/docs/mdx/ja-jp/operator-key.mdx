---
title: オペレーターキー
---

オペレーターキーは、チームサーバーにログインしてアクセスセッションを作成するために使う認証キーです。

チームサーバーのホストで次を実行します。

```bash
nukerat server key add bill
```

キーは出力に表示され、コマンドを実行したディレクトリに `.key` ファイルが作成されます。

生成済みキーを一覧するには次を実行します。

```bash
nukerat server key list
```

キーを削除するには:

```bash
nukerat server key rem bill
```

## キーの構造

```
bill:1pDi0uSLlFKfCjjHPL9uZAlP:1789429491513043059V5Kua8T5ug3ZHcVt…
```

オペレーターキーはコロンで区切られた 3 部分からなります。

1. オペレーター名（識別用のみ）
2. パスワード（サーバー側で bcrypt により検証）
3. シークレット

キー使用時、クライアントは `user`、`pass`、`secret` を `/auth/login` への POST で送り、セッション JWT を取得します。

## セッションの有効期間

デフォルトでは JWT セッションは 7 日間有効です（サーバー設定の `server.keys.jwt.duration`、デフォルト `7d`）。期限切れになると、認証が必要な機能を使おうとした際にエラートーストが表示されます。

セッションを更新するには、保存したキーで再度ログインしてください。
