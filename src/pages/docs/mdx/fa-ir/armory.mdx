title: آرسنال
---

آرسنال مجموعهٔ آماده‌ای از ۵۴۳ ابزار (BOF و فایل‌های اجرایی .NET) است تا بتوانید آن‌ها را به‌سرعت روی میزبان مشخص‌شده دانلود و اجرا کنید.

همهٔ ابزارها از مخزن رسمی armory در NukeRat در آدرس [**github.com/nukeratframework/armory**](https://github.com/nukeratframework/armory) دانلود می‌شوند.

به‌صورت پیش‌کامپایل‌شده به‌طور خودکار دانلود می‌شوند، اما می‌توانید آن‌ها را دستی هم بسازید. برای این کار می‌توانید:

1. آن‌ها را بسازید و دستی به پوشهٔ `server/infra/bin/armory/` اضافه کنید
2. مقدار `repository` را در بخش `[server.armory]` در `server/server.conf` طوری تنظیم کنید که به میزبان release گیت‌هاب خودتان اشاره کند

## دستورات

به‌طور پیش‌فرض، NukeRat همراه با باینری‌های armory ازپیش‌کامپایل‌شده عرضه نمی‌شود. برای نصب آن‌ها روی team server از دستورات armory استفاده کنید:

| دستور | عمل |
| --- | --- |
| `armory` | فهرست ابزارهای موجود و توضیحات کوتاه |
| `armory install all` | دانلود همهٔ ابزارها از آخرین بستهٔ release |
| `armory install &lt;tool&gt;` | دانلود فایل‌های یک ابزار |
| `armory update` | به‌روزرسانی اندیس armory (`armory.json`) از مخزن |
| `armory update &lt;tool&gt;` | به‌روزرسانی اندیس و دانلود مجدد یک ابزار |
| `armory remove &lt;tool&gt;` | حذف فایل‌های cache‌شدهٔ آن ابزار |
| `help &lt;command&gt;` | نمایش راهنما برای دستور یک ابزار |
