---
title: میانبرها
---

میانبرهای صفحه‌کلید کلاینت NukeRat. در macOS، **Ctrl** در این ترکیب‌ها **⌘** است و **Alt** همان **⌥** است. میانبرهای اندازهٔ قلم ترمینال همیشه از کلید **Ctrl** استفاده می‌کنند.

## فضای کار

| میانبر | کار |
| --- | --- |
| Alt+T | باز کردن ترمینال |
| Alt+F | باز کردن مرورگر پوشه |
| Alt+R | باز کردن فرایندها |
| Alt+S | باز کردن نشست‌ها |
| Alt+A | باز کردن عامل هوش مصنوعی |
| Alt+K | باز کردن اعتبارنامه‌ها |
| Alt+1 … Alt+9 | رفتن به همان زبانهٔ فضای کار، اگر وجود داشته باشد |
| Ctrl+Shift+W | فضای کار تازه |
| Shift+Alt+W | بستن فضای کار جاری |
| Ctrl+W | بستن پنل زیر اشاره‌گر |

## منوی NukeRat

پنل‌های شناور نوار بالا را باز می‌کنند.

| میانبر | کار |
| --- | --- |
| Shift+S | Servers |
| Shift+L | Listeners |
| Shift+I | Implants |
| Shift+N | Network |
| Shift+Q | Queue |
| Shift+E | Logs |

## نما

| میانبر | کار |
| --- | --- |
| F11 | تمام‌صفحه |
| Ctrl++ | بزرگ‌نمایی |
| Ctrl+- | کوچک‌نمایی |
| Ctrl+0 | بازنشانی بزرگ‌نمایی |
| Ctrl+R | بارگذاری دوبارهٔ پنجره |
| Ctrl+Shift+I | ابزارهای توسعه |

## برنامه

| میانبر | کار |
| --- | --- |
| F1 | باز کردن مستندات |
| Ctrl+Shift+Q | خروج |
| Escape | منوهای باز را می‌بندد. پنل شناور را هم می‌بندد، مگر اینکه گفتگویی داخل آن Escape را گرفته باشد |

## ترمینال

اشاره‌گر را روی ترمینال بگذارید. **Ctrl** در همهٔ سکوها همان **Ctrl** است. در macOS، **Alt** در ترکیب آخر **⌥** است.

| میانبر | کار |
| --- | --- |
| Ctrl+پیمایش به بالا | بزرگ‌تر کردن قلم |
| Ctrl+پیمایش به پایین | کوچک‌تر کردن قلم |
| Ctrl+Alt+0 | بازنشانی اندازهٔ قلم |
