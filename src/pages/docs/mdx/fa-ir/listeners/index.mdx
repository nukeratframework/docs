title: شنونده‌ها
---

در NukeRat، **listener** هر سرویس یا روتینی است که فعالانه روی یک پورت گوش می‌دهد.

انواع listener عبارت‌اند از:

- **Channel (کانال)**: کانال ارتباطی که ایمپلنت‌ها از آن برای دریافت دستور و ارسال خروجی استفاده می‌کنند.
- **File Server (سرور فایل)**: سرور فایل برای میزبانی فایل‌ها یا سرو کردن برنامه‌های ساده.

## نحوهٔ ایجاد

**NukeRat** > [شنونده‌ها](/docs/listeners) > **Add** را باز کنید و نوع را انتخاب کنید:

- **Listeners**
  - [کانال](/docs/listeners/channel)
  - [سرور فایل](/docs/listeners/file-server)
