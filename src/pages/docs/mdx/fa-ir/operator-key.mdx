---
title: کلید اپراتور
---

کلید اپراتور کلید احراز هویتی است برای ورود و ایجاد session دسترسی روی team server.

روی میزبان team server اجرا کنید:

```bash
nukerat server key add bill
```

کلید در خروجی چاپ می‌شود و فایل `.key` در همان دایرکتوری که دستور را اجرا کردید ساخته می‌شود.

برای فهرست همهٔ کلیدهای تولیدشده:

```bash
nukerat server key list
```

برای حذف کلید:

```bash
nukerat server key rem bill
```

## ساختار کلید

```
bill:1pDi0uSLlFKfCjjHPL9uZAlP:1789429491513043059V5Kua8T5ug3ZHcVt…
```

کلید اپراتور سه بخش دارد که با علامت دو نقطه (:) از هم جدا شده‌اند:

1. نام اپراتور (فقط برای شناسایی)
2. Password (روی سرور با bcrypt بررسی می‌شود)
3. Secret

هنگام استفاده از کلید، کلاینت `user`، `pass` و `secret` را در POST به `/auth/login` می‌فرستد تا JWT session بگیرد.

## مدت session

به‌طور پیش‌فرض JWT session ۷ روز معتبر است (`server.keys.jwt.duration` در config سرور، پیش‌فرض `7d`). وقتی منقضی شود، هنگام استفاده از قابلیت‌هایی که احراز هویت می‌خواهند toast خطا می‌بینید.

برای تمدید session دوباره با کلید ذخیره‌شده وارد شوید.
