---
title: ایمپلنت‌ها
---

ایمپلنت‌ها باینری‌هایی هستند که روی میزبان‌های compromised اجرا می‌شوند. در چارچوب‌های دیگر اغلب «beacon» هم نامیده می‌شوند.

می‌توانید مستقیماً از کلاینت NukeRat بسازیدشان. برای نحوهٔ ساخت [ایجاد](/docs/client/implants/creation) را ببینید.

## فلسفهٔ طراحی ایمپلنت

ایمپلنت‌های NukeRat حول سفارشی‌سازی انعطاف‌پذیر ساخته شده‌اند تا ایمپلنت منحصربه‌فرد بسازید. عمدتاً شامل:

- **ساخت ایمپلنت**: از کلاینت NukeRat می‌توانید هدر PE، کد preface، رشته‌های PE و گزینه‌های دیگر را سفارشی کنید.
- **API ایمپلنت**: check-in و ترافیک task از [API listener ایمپلنت](/docs/rest-api/implants) (**POST** HTTP رمزنگاری‌شده روی `endpointPath` کانال) استفاده می‌کند، نه مسیرهای REST مدیریت team server زیر `/api/...`.


## دور زدن تشخیص

ایمپلنت‌های NukeRat چند تکنیک evasion ضروری برای سناریوهای مدرن دارند؛ مهم‌ترینشان indirect syscalls و sleep masking است.

بیشتر evasion به ایمپلنت Windows وابسته است. Linux و macOS فعلاً obfuscation رشته (Off، Xor یا RC4) دارند و گزینه‌های artifact PE فقط برای Windows است.
