---
title: کلاینت
description: نمای کلی کلاینت NukeRat
---

کلاینت NukeRat رابط اپراتور برای یک یا چند team server است. پس از اتصال و احراز هویت سرورها، از نوار بالا و منوی **NukeRat** برای مدیریت listenerها، ایمپلنت‌ها و عملیات استفاده کنید.

## شروع کار

1. team serverها را اضافه کنید و با کلید اپراتور احراز هویت کنید. [Servers](/docs/servers) را ببینید.
2. کلیدهای اپراتور را روی team server بسازید. [Operator key](/docs/operator-key) در بخش Server مستندات را ببینید.

## موضوعات

- [Interface](/docs/interface): نمای workspace مثل terminal، folder explorer و hosts
- [Servers](/docs/servers): اتصال و احراز هویت team serverها
- [Listeners](/docs/listeners): مدیریت listenerهای C2
- [Implants](/docs/client/implants): ساخت و مدیریت payload ایمپلنت
- [Armory](/docs/armory): ابزار BOF در کلاینت
- [Pivoting](/docs/pivoting): relayها و pivot شبکه
- [AI agents](/docs/agents): قابلیت‌های agent هوش مصنوعی کلاینت
- [NukeScript](/docs/nukescripts): اسکریپت‌های خودکارسازی
- [Reports](/docs/reports): گزارش‌گیری
- [Monitoring](/docs/monitoring): نمای پایش
