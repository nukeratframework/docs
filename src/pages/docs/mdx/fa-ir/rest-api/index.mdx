اکوسیستم NukeRat دو نوع API دارد:

1. **API ایمپلنت**: ایمپلنت‌ها با این API داده را از و به سرور تیم ارسال و دریافت می‌کنند. اگر قصد دارید ایمپلنت خود را از صفر بسازید، از این API استفاده کنید.
2. **API سرور تیم**: کلاینت NukeRat با این API ایمپلنت‌ها و سرور تیم را مدیریت می‌کند. اگر می‌خواهید NukeRat را با عامل‌های AI پویا یا یکپارچگی‌های بسیار خاص ادغام کنید، از این API استفاده کنید.
