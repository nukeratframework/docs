## نحوهٔ کار

implant فرایندهای در حال اجرا را فهرست می‌کند و نتیجه را به قالب JSON سفارشی برای رندر در کلاینت تبدیل می‌کند.

### Windows

از `kernel32.dll` (`CreateToolhelp32Snapshot`, `Process32FirstW`, `Process32NextW`, `OpenProcess`, `QueryFullProcessImageNameW`) و `iphlpapi.dll` (`GetExtendedTcpTable`) استفاده می‌کند. منطق اصلی در `implants/windows/stageless/capabilities/process.nim` است.

### Linux

`/proc` (`stat`, `status`, `exe`) و `/proc/net/tcp` را می‌خواند. منطق اصلی در `implants/linux/stageless/capabilities/process.nim` است.

### MacOS

از ماژول `macapi` (`ListProcessIDs`, `ReadProcessStat`, `ReadProcessStatus`, `GetTcpPidMap`) استفاده می‌کند. منطق اصلی در `implants/mac/stageless/capabilities/process.go` است.
