تب اعتبارنامه‌ها دو هدف اصلی دارد:

1. به‌اشتراک‌گذاری آسان‌تر اعتبارنامه‌ها بین اپراتورها
2. الصاق خودکار آن‌ها به گزارش عملیات

می‌توانید تب **Credentials** را از <span className="inline-flex items-center gap-1 whitespace-nowrap align-middle">آیکون <KeyRound size={18.5} className="shrink-0 ml-1.5 mr-1.5" /></span> در نوار بالا، یا از **Tabs** > **Credentials** باز کنید.

<ImageZoom src={credentials} alt="اعتبارنامه‌ها" className="tutorial_img" />

## نحوهٔ استفاده

برای استفاده از تب اعتبارنامه‌ها این مراحل را دنبال کنید:

  <Steps>
    <Step>
      ### افزودن اعتبارنامه
      برای افزودن اعتبارنامهٔ جدید روی دکمهٔ **Add** کلیک کنید.
    </Step>
    <Step>
      ### پر کردن فیلدها
      هر اعتبارنامه به یک میزبان و یک team server وابسته است؛ پس هر دو باید از قبل پیکربندی شده باشند.
      <ImageZoom src={credentialsAdd} alt="افزودن اعتبارنامه" className="h-[30rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />
    </Step>
    <Step>
      ### دسترسی به اعتبارنامه
      پس از افزودن، روی ردیف اعتبارنامه دوبار کلیک کنید تا پنل کناری باز شود و متن اعتبارنامهٔ ذخیره‌شده را ببینید.
    </Step>
  </Steps>

توجه کنید فهرست اعتبارنامه‌ها نیازی به انتخاب میزبان یا سرور ندارد. با باز کردن تب، کلاینت از قبل درخواستی به هر team server پیکربندی‌شده می‌فرستد.
