NukeRat 생태계에는 두 가지 유형의 API가 있습니다.

1. **임플란트 API**: 임플란트가 팀 서버와 데이터를 주고받을 때 사용합니다. 임플란트를 처음부터 직접 만들 계획이라면 이 API를 사용하세요.
2. **팀 서버 API**: NukeRat 클라이언트가 임플란트와 팀 서버를 관리할 때 사용합니다. 동적 AI 에이전트나 매우 특수한 커스텀 통합과 NukeRat을 연동하려면 이 API를 사용하세요.
