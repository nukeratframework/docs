팀 서버용 API 엔드포인트입니다.

`/auth/login`을 제외한 모든 엔드포인트에는 `Authorization: Bearer <token>` 헤더가 필요합니다. 토큰은 `/auth/login`에서 발급받습니다.

---

### 인증

운영자의 인증 세션을 생성하고 검증합니다.

<Collapsible className="mb-4">
  <CollapsibleTrigger className="flex w-full items-center gap-3 rounded-[11px] border border-fd-border bg-fd-card px-[15px] py-[10px] text-left text-sm font-medium">
    <span className="rounded-[6px] bg-emerald-500/15 px-2 py-1 font-semibold text-emerald-400">POST</span>
    <span className="font-[400] text-[16px]">/auth/login</span>
  </CollapsibleTrigger>
  <CollapsibleContent className="mt-3 rounded-lg border border-fd-border bg-fd-card p-4 text-sm text-fd-muted-foreground">
    <h2 className="api-section-title api-section-title--explanation">설명</h2>
    사용자 이름, 비밀번호, secret으로 운영자를 인증합니다. 인증 JWT를 반환합니다. `user`, `pass`, `secret` 중 하나라도 없거나 비어 있으면 응답은 `{"status": "failure", "message": "user, pass and secret are required"}`입니다.

    **중요:** `user`, `pass`, `secret`은 팀 서버에서 생성한 운영자 키에서 추출해야 합니다. 예:

    ```
    admin:F9VhtamxN:yKu31sGWKXYPbnRq52cg
    ```

    위 예에서:

    
    **user** = `admin`<br/>
    **pass** = `F9VhtamxN`<br/>
    **secret** = `yKu31sGWKXYPbnRq52cg`<br/>

    <h2 className="api-section-title api-section-title--primary">요청</h2>

    {

    임플란트에 터미널 명령을 보냅니다.

    <h2 className="api-section-title api-section-title--primary">특수 케이스: `-f` / `--file`</h2>

    파일 바이트는 다음 세 가지 방법 중 하나로 첨부할 수 있습니다.

    1. `command` 문자열 끝에 `--__tmp_file_bytes__`와 base64 페이로드를 붙입니다(NukeRat 클라이언트와 동일).
    2. 별도 JSON 필드 `__tmp_file_bytes__`에 base64 페이로드를 보냅니다(`command` 문자열은 그대로 둡니다).
    3. 요청 본문을 raw 파일 바이트로 보내고, URL 인코딩된 JSON 메타데이터 객체를 `x-terminal-meta` 헤더에 넣습니다(JSON 본문과 동일한 필드). 서버는 raw 본문을 업로드 페이로드로 저장합니다.

    **예(인라인 플래그):**

    ```
    upload -f payload.exe -o C:/Temp/payload.exe --__tmp_file_bytes__ SGVsbG8=
    ```

    <h2 className="api-section-title api-section-title--primary">특수 케이스: `download`</h2>

    `download` 명령은 `message`에 base64가 담긴 단일 JSON 본문을 반환하지 않습니다. `Content-Type: application/x-ndjson`으로 응답합니다: 줄 단위 JSON 이벤트(`progress`, 이어서 raw 바이트가 오는 `chunk` 메타데이터, 그다음 `success` 또는 `failure`). 선택 필드 `download_id`와 `download_file`은 서버 다운로드 큐에서 진행률을 추적합니다.

    <h2 className="api-section-title api-section-title--primary">요청</h2>

    }
