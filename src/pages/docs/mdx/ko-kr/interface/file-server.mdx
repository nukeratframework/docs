File Server 탭을 사용하면 NukeRat에 이미 구성된 파일 서버를 관리할 수 있습니다. 페이로드 등 파일을 빠르고 효율적으로 호스팅하는 데 도움이 됩니다.

상단 바의 <span className="inline-flex items-center gap-1 whitespace-nowrap align-middle"><Globe size={18.5} className="shrink-0 ml-1.5 mr-1.5" /> 아이콘</span>에서 **File Server** 탭을 열거나, **Tabs** > **File Server**에서 열 수 있습니다.

<ImageZoom src={fileServer} alt="File Server" className="tutorial_img" />

## 사용 방법

File Server 탭을 사용하려면 다음 단계를 따르세요.

  <Steps>
    <Step>
      ### 파일 서버 리스너 생성
      먼저 **File server** 유형의 리스너를 만듭니다. 자세한 내용은 [Listeners](/docs/listeners) 섹션을 참조하세요.
    </Step>
    <Step>
      ### 파일 서버 선택
      탭 상단에서 서버 선택기를 열고 관리할 파일 서버 리스너를 선택하세요.
    </Step>
    <Step>
      ### 파일 업로드
      마지막으로 호스팅할 파일을 업로드합니다.
    </Step>
  </Steps>

## 추가 팁

NukeRat 파일 서버는 파일 호스팅에만 국한되지 않습니다. 가짜 로그인 페이지 같은 소셜 엔지니어링용 애플리케이션을 호스팅하는 데도 사용할 수 있습니다.
