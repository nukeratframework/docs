키로거 탭은 스크린샷 탭과 같이 패시브 기능입니다. 호스트에서 이미 캡처된 키만 읽고 편집하며, 스스로 캡처를 시작하지 않습니다.

상단 바의 <span className="inline-flex items-center gap-1 whitespace-nowrap align-middle"><Keyboard size={18.5} className="shrink-0 ml-1.5 mr-1.5" /> 아이콘</span>에서 **Keylogger** 탭을 열거나, **Tabs** > **Keylogger**에서 열 수 있습니다.

<ImageZoom src={keylogger} alt="Keylogger" className="tutorial_img" />

## 사용 방법

키로거 탭을 사용하려면 다음 단계를 따르세요.

  <Steps>
    <Step>
      ### 키로거 시작
      터미널에서 `keylogger start`를 실행하여 키로거를 시작합니다. Windows에서는 `--method [keystate|boardstate]` 플래그로 캡처 방식을 변경할 수 있습니다.
    </Step>
    <Step>
      ### 키로거 탭 새로 고침
      키로거 탭은 자동으로 갱신되지 않으므로 <RefreshCw size={18.5} className="w-4 ml-1.5 inline-flex items-center gap-1 whitespace-nowrap align-middle" />를 클릭하여 수동으로 새로 고치세요.
    </Step>
  </Steps>

키로거 탭은 호스트나 서버를 선택할 필요가 없습니다. 구성된 모든 팀 서버에 이미 요청이 전송됩니다.

## 동작 방식

키로거는 별도 백그라운드 스레드에서 실행되며 캡처한 키를 배치로 서버에 보냅니다.

### Windows

앞서 언급했듯 Windows 키로거는 두 가지 캡처 방식을 지원합니다. 하나는 OPSEC을 우선하고 다른 하나는 캡처 정확도를 우선합니다.

- **keystate**는 `SetWindowsHookEx`를 통한 저수준 키보드 후크를 사용합니다. 후크 모니터링에 더 잘 보이지만 광범위한 폴링은 피합니다.

- **boardstate**는 `--method`를 생략할 때 기본값입니다. `user32.dll`의 `GetAsyncKeyState`를 사용하고 루프에서 키 상태를 폴링합니다. 후크는 설치하지 않지만 반복 폴링은 눈에 띌 수 있습니다.

핵심 로직은 `implants/windows/stageless/capabilities/keylogger.nim`에 있습니다.

### Linux

X11(`libX11.so`)로 `XOpenDisplay` 및 `XQueryKeymap`을 사용합니다. `DISPLAY`가 필요합니다. 핵심 로직은 `implants/linux/stageless/capabilities/keylogger.nim`에 있습니다.

### MacOS

MacOS에서는 이 기능을 지원하지 않습니다.
