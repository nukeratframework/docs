자격 증명 탭은 두 가지 주요 목적이 있습니다.

1. 운영자 간 자격 증명을 더 쉽게 공유
2. 작전 보고서에 자동으로 첨부

상단 바의 <span className="inline-flex items-center gap-1 whitespace-nowrap align-middle"><KeyRound size={18.5} className="shrink-0 ml-1.5 mr-1.5" /> 아이콘</span>에서 **Credentials** 탭을 열거나, **Tabs** > **Credentials**에서 열 수 있습니다.

<ImageZoom src={credentials} alt="Credentials" className="tutorial_img" />

## 사용 방법

자격 증명 탭을 사용하려면 다음 단계를 따르세요.

  <Steps>
    <Step>
      ### 자격 증명 추가
      **Add** 버튼을 클릭하여 새 자격 증명을 추가합니다.
    </Step>
    <Step>
      ### 필드 입력
      각 자격 증명은 호스트와 팀 서버에 연결되므로 둘 다 미리 구성되어 있어야 합니다.
      <ImageZoom src={credentialsAdd} alt="Credentials Add" className="h-[30rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />
    </Step>
    <Step>
      ### 자격 증명 열기
      추가한 후 자격 증명 행을 더블 클릭하면 사이드 패널이 열리고 저장된 자격 증명 텍스트를 볼 수 있습니다.
    </Step>
  </Steps>

자격 증명 목록은 호스트나 서버를 선택할 필요가 없습니다. 탭을 열면 클라이언트가 구성된 모든 팀 서버에 이미 요청을 보냅니다.
