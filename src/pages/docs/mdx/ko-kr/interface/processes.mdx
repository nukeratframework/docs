## 동작 방식

임플란트가 실행 중인 프로세스를 열거하고 결과를 클라이언트가 렌더링할 사용자 정의 JSON 형식으로 변환합니다.

### Windows

`kernel32.dll`(`CreateToolhelp32Snapshot`, `Process32FirstW`, `Process32NextW`, `OpenProcess`, `QueryFullProcessImageNameW`) 및 `iphlpapi.dll`(`GetExtendedTcpTable`)을 사용합니다. 핵심 로직은 `implants/windows/stageless/capabilities/process.nim`에 있습니다.

### Linux

`/proc`(`stat`, `status`, `exe`) 및 `/proc/net/tcp`를 읽습니다. 핵심 로직은 `implants/linux/stageless/capabilities/process.nim`에 있습니다.

### MacOS

`macapi` 모듈(`ListProcessIDs`, `ReadProcessStat`, `ReadProcessStatus`, `GetTcpPidMap`)을 사용합니다. 핵심 로직은 `implants/mac/stageless/capabilities/process.go`에 있습니다.
