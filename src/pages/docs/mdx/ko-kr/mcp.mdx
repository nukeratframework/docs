MCP를 사용하면 모든 MCP 호스트의 에이전트가 team server를 호출할 수 있습니다. listeners, sessions, terminal, implants 등 [team server API](/docs/rest-api/team-server)와 동일한 범위입니다

## team server에서 사용 설정

저장소 루트에서:

```bash
./nukerat.py server mcp enable
```

MCP 인증이 만료되면 아래 명령으로 갱신합니다.

```bash
./nukerat.py server mcp reauth
```

MCP 비활성화:

```bash
./nukerat.py server mcp disable
```

`[mcp]` 선택 항목: `base_url`(비우면 `[server]`의 host/port/TLS에서 유도), `tls_verify`(기본값 `true`)

## 호스트 설정

저장소의 **`server/mcp.json`**을 MCP 서버 항목으로 사용합니다(경로는 저장소 루트 기준):

```json
{
  "mcpServers": {
    "nukerat": {
      "command": "./server/.venv/bin/python",
      "args": ["./server/workers/mcp_server/main.py"],
      "cwd": "./server/workers/mcp_server",
      "env": {
        "NUKERAT_BASE_URL": "http://127.0.0.1:9000",
        "NUKERAT_TLS_VERIFY": "false"
      }
    }
  }
}
```

<Callout type="warning">
  `9000`은 team server 기본 포트입니다. `server.conf`에서 포트를 바꿨다면 `NUKERAT_BASE_URL`도 같은 호스트와 포트로 맞추세요.
</Callout>
