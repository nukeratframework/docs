title: 임플란트

임플란트는 침해된 호스트에서 실행되는 바이너리입니다. 다른 프레임워크에서는 흔히 "beacon"이라고도 부릅니다.

NukeRat 클라이언트에서 직접 생성할 수 있습니다. 임플란트 생성 방법은 [생성](/docs/client/implants/creation)을 참고하세요.

## 임플란트 설계 철학

NukeRat 임플란트는 유연한 사용자 지정을 중심으로 설계되어 고유한 임플란트를 만들 수 있습니다. 주로 다음에 해당합니다.

- **임플란트 생성**: NukeRat 클라이언트에서 PE 헤더, preface 코드, PE strings 등 옵션을 직접 사용자 지정할 수 있습니다.
- **임플란트 API**: 임플란트 check-in 및 task 트래픽은 [임플란트 리스너 API](/docs/rest-api/implants)(채널 `endpointPath`의 암호화 HTTP **POST**)를 사용하며, `/api/...` 아래 팀 서버 관리 REST 경로는 사용하지 않습니다.


## 탐지 회피

NukeRat 임플란트에는 현대 시나리오에 필수적인 여러 회피 기법이 포함되어 있으며, indirect syscalls와 sleep masking이 대표적입니다.

대부분의 회피 기능은 Windows 임플란트에 묶여 있습니다. Linux 및 macOS 임플란트는 현재 문자열 난독화(Off, Xor, 또는 RC4)를 지원하며 PE artifact 옵션은 Windows 전용입니다.
