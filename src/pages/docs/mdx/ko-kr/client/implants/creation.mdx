이 주제는 NukeRat 클라이언트에서 임플란트를 만드는 방법을 다룹니다. 클라이언트는 두 가지 임플란트 베이스를 제공합니다. **Stageless**와 **Loader**입니다.

- **Stageless**: HTTP, HTTPS, custom HTTP, TCP, SMB(SMB는 Windows만) 리스너 채널로 연결하는 전체 임플란트
- **Loader**: 구성한 URL에서 외부 스테이지를 내려받는 최소 임플란트
- **Relay stageless**(구성): 피벗 채널(**TCP**는 모든 OS, **SMB**는 Windows)을 사용하고 팀 서버가 아닌 다른 임플란트와 직접 통신하는 stageless 임플란트

## Stageless 임플란트

기본 stageless 임플란트를 만들려면 아래 단계를 따르세요.

  <Steps>
    <Step>
      ### 임플란트 생성 탭 열기
      **NukeRat > Implants**로 이동합니다.
    </Step>
    <Step>
      ### 임플란트 베이스 선택
      **Stageless** 베이스를 선택합니다.
    </Step>
    <Step>
      ### 컴파일 서버 선택
      컴파일 서버는 임플란트를 컴파일하는 데 사용하는 서버입니다. **NukeRat** > **Servers**에서 서버가 이미 구성되어 있어야 합니다.
      <ImageZoom src={compileServer} alt="Compile Server" className="h-[4.5rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />
      서버 구성에 대해서는 [Servers](/docs/servers)를 참고하세요.
    </Step>
    <Step>
      ### OS 및 아키텍처 선택
      임플란트가 실행될 플랫폼과 아키텍처를 선택합니다. Windows 빌드는 **x64**만 대상으로 합니다. Linux와 macOS에서는 **amd** 또는 **arm** CPU를 선택합니다. 클라이언트는 두 CPU 모두 **x64**(64-bit) 임플란트를 빌드합니다.
      <ImageZoom src={arch} alt="Architecture" className="h-[12rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />
    </Step>
    <Step>
      ### C2 구성
      통신을 리스너에서 만든 채널로 연결합니다. 아래 예시는 HTTP 채널을 사용합니다.
      <ImageZoom src={c2} alt="C2" className="h-[11rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />
      HTTP 채널 생성 방법은 [HTTP 채널 생성](/docs/listeners/channel#http-채널-생성)을 참고하세요. 암호화된 POST 프로토콜(경로, body 템플릿, 상태 코드)은 [임플란트 리스너 API](/docs/rest-api/implants)를 참고하세요.
    </Step>
    <Step>
      ### 임플란트 빌드
      **Build**를 클릭해 임플란트를 컴파일합니다.
    </Step>
  </Steps>


## Loader 임플란트

생성은 stageless 임플란트와 유사하며 차이점이 몇 가지 있습니다. Loader C2는 **HTTP** 및 **custom** 채널만 지원합니다. 아래 단계를 참고하세요.

  <Steps>
    <Step>
      ### Loader 베이스 선택
      베이스를 **Stageless**에서 **Loader**로 변경합니다.
    </Step>
    <Step>
      ### 페이로드 구성
      **Stage** 탭에서 페이로드 URL을 설정합니다.

      shellcode는 shellcode 형식으로 만든 stageless 임플란트가 됩니다.
      <ImageZoom src={urlStage} alt="URL Stage" className="h-[4.5rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />
    **Tip**: NukeRat **File server** 기능으로 페이로드를 빠르게 호스팅할 수 있습니다. 자세한 내용은 [파일 서버](/docs/listeners/file-server#파일-서버-생성)를 참고하세요.
    </Step>
  </Steps>

## Relay stageless 임플란트

Relay stageless 임플란트도 여전히 **Stageless** 베이스 빌드입니다. 차이는 C2입니다. **Channel**에서 피벗 프로토콜(**TCP**, Windows에서는 **SMB**)을 선택합니다. **Relay implant** 필드에서 팀 서버 쪽으로 트래픽을 전달할 upstream 임플란트(호스트, 포트 또는 SMB pipe)를 지정합니다.

대상 호스트에 인터넷으로 나가는 경로가 없을 때 유용합니다.

생성은 stageless 임플란트와 동일한 단계를 따르며 C2 구성만 다릅니다.

<ImageZoom src={relayImplant} alt="Relay Implant" className="h-[18rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />

지원되는 모든 OS에서는 **TCP**를 사용합니다. **SMB**는 Windows 임플란트에만 사용합니다. 대상 호스트에는 upstream 임플란트에 relay가 이미 구성되어 있어야 합니다. relay에 대해서는 [Relay](/docs/pivoting/relay#사용-방법)를 참고하세요.
