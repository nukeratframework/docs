작전 중에는 무슨 일이 일어나는지 추적하는 것이 항상 유용합니다. NukeRat에는 팀 서버에 직접 접속해 로그를 뒤지지 않아도 되도록 돕는 기능이 두 가지 있습니다.

## 명령 큐

**NukeRat** > **Queue**에서 실행 큐의 모든 명령을 볼 수 있습니다. 표에는 실행 대기 중인 명령과 이미 실행된 명령이 포함됩니다. 다음에 유용합니다.

- 실수로 추가한 명령 제거(임플란트가 받기 전)
- 닫은 터미널 탭에서 실행한 명령의 출력 확인
- 명령 실패 원인 오류 확인

<ImageZoom src={commandQueue} alt="Command queue" className="h-[30rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />

표에 나열된 명령은 터미널 탭에만 한정되지 않습니다. 폴더 탐색기 및 프로세스 탭의 활동도 포함될 수 있습니다.

표 행을 더블 클릭하면 해당 큐 이벤트의 모든 상세를 볼 수 있습니다.

큐에서 명령을 삭제할 수도 있습니다. 선택한 뒤 **Delete**를 클릭하면 데이터베이스에서 제거되며, 아직 전달되지 않았다면 임플란트가 실행하지 않습니다.

## 이벤트 로그

**NukeRat** > **Event Log**에서 특정 팀 서버의 로그를 봅니다. 로그는 다음으로 묶입니다.

- **Listeners**: HTTP 채널 및 파일 서버 리스너의 트래픽과 동작(`listeners.log`)
- **Launcher**: 서버 시작 및 런처 메시지(`server.log`)
- **Server**: 팀 서버 API 및 코어의 오류 및 정보 메시지(`server.log`)

Event Log 뷰는 팀 서버 [`GET /api/logs/`](/docs/rest-api/team-server) 엔드포인트를 통해 `server.log`와 `listeners.log`를 읽습니다.
