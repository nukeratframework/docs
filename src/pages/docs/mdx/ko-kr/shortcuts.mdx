---
title: 단축키
---

NukeRat 클라이언트의 키보드 단축키입니다. macOS에서 이 조합의 **Ctrl**은 **⌘**이고 **Alt**는 **⌥**입니다. 터미널 글자 크기 단축키는 항상 **Ctrl** 키를 사용합니다.

## 작업 공간

| 단축키 | 동작 |
| --- | --- |
| Alt+T | 터미널 열기 |
| Alt+F | 폴더 탐색기 열기 |
| Alt+R | 프로세스 열기 |
| Alt+S | 세션 열기 |
| Alt+A | AI 에이전트 열기 |
| Alt+K | 자격 증명 열기 |
| Alt+1 … Alt+9 | 해당 작업 공간 탭으로 전환 (탭이 있을 때) |
| Ctrl+Shift+W | 새 작업 공간 |
| Shift+Alt+W | 현재 작업 공간 닫기 |
| Ctrl+W | 포인터 아래 패널 닫기 |

## NukeRat 메뉴

상단 바의 떠 있는 패널을 엽니다.

| 단축키 | 동작 |
| --- | --- |
| Shift+S | Servers |
| Shift+L | Listeners |
| Shift+I | Implants |
| Shift+N | Network |
| Shift+Q | Queue |
| Shift+E | Logs |

## 보기

| 단축키 | 동작 |
| --- | --- |
| F11 | 전체 화면 전환 |
| Ctrl++ | 확대 |
| Ctrl+- | 축소 |
| Ctrl+0 | 확대/축소 초기화 |
| Ctrl+R | 창 다시 로드 |
| Ctrl+Shift+I | 개발자 도구 전환 |

## 애플리케이션

| 단축키 | 동작 |
| --- | --- |
| F1 | 문서 열기 |
| Ctrl+Shift+Q | 종료 |
| Escape | 열린 메뉴를 닫습니다. 떠 있는 패널도 닫습니다. 그 안의 대화 상자가 Escape를 쓰고 있으면 패널은 닫히지 않습니다 |

## 터미널

터미널 위에 포인터를 둡니다. **Ctrl**은 모든 플랫폼에서 **Ctrl**입니다. macOS에서 마지막 조합의 **Alt**는 **⌥**입니다.

| 단축키 | 동작 |
| --- | --- |
| Ctrl+스크롤 위 | 글자 크기 키우기 |
| Ctrl+스크롤 아래 | 글자 크기 줄이기 |
| Ctrl+Alt+0 | 글자 크기 초기화 |
