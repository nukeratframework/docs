NukeRat에서는 침해된 호스트를 통해 포트 포워딩을 설정하여 내부 네트워크의 특정 포트에 도달할 수 있습니다.

팀 서버가 listen 포트에 바인딩합니다. 연결은 선택한 임플란트를 통해 내부 호스트 및 포트로 전달됩니다.

## 구성 방법

포트 포워드를 만들려면 아래 단계를 따르세요.

  <Steps>
    <Step>
      ### Network 창 열기
      **NukeRat** > **Network**로 이동한 뒤 **Add**를 클릭합니다.
    </Step>
    <Step>
      ### 포트 포워딩 구성
      <ImageZoom src={socks} alt="Port forward add" className="h-[15rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />
      - **Team server**: 리스너 API 엔드포인트(폼 상단의 호스트 및 포트)
      - **Type**: `port forwarding`
      - **Host tag**: 내부 대상에 연결을 여는 임플란트
      - **Listen port**: 팀 서버에서 여는 포트
      - **Protocol**: TCP만(현재 팀 서버가 허용하는 유형)
      - **Forward host**: 임플란트를 통해 도달할 내부 IP 또는 호스트명
      - **Forward port**: 임플란트를 통해 도달할 내부 포트

      필드를 설정한 뒤 **Create**를 클릭합니다.
    </Step>
  </Steps>

완료되면 포트 포워드가 Network 테이블에 표시됩니다. `<team_server_host>:<listen_port>`에 연결하면 임플란트를 통해 `forward_host:forward_port`에 도달합니다.
