## 개요

NukeRat는 레드 팀 캠페인에 초점을 맞춘 후 침투 프레임워크입니다. 비교하자면 Cobalt Strike, Havoc 등과 같은 범주에 속합니다.

## 목적

NukeRat는 레드 팀원이 시장의 다른 프레임워크를 직접 다루며 쌓은 경험에서 나왔습니다. 네, 이미 강력한 프레임워크가 있고 오픈 소스 프로젝트도 포함되어 있지만, 각각은 일상 업무를 방해할 수 있는 한계가 남아 있습니다.

그래서 NukeRat는 오늘날 도구들이 남긴 공백을 메우면서, 동시에 조금 다른 느낌의 기능도 가져오도록 만들어졌습니다.

이 모든 것은 *"Make it simple"*를 핵심 모토로 삼으며 단순함을 유지하는 가운데 이루어집니다.

## 기능

NukeRat가 제공하는 것을 요약하면 다음과 같습니다.

- <span className='font-medium'>Armory</span>: 공식 armory 저장소에서 가져올 수 있는, 바로 쓸 수 있는 유틸리티(BOF 및 .NET 도구) 543개 모음.
- <span className='font-medium'>Evasion:</span> Windows 임플란트에는 indirect syscalls, sleep masking, 문자열 난독화 등 현대 환경에 필요한 기법이 기본으로 포함되어 있습니다.
- <span className='font-medium'>Cross platform:</span> 기본 설정만으로 Linux와 macOS를 지원하며 ARM 기반 시스템도 포함됩니다.
- <span className='font-medium'>Custom channels:</span> 사용자 정의 본문 템플릿이 있는 HTTP·HTTPS 채널, Telegram·Dropbox 등 서드파티 플랫폼용 완전 사용자 정의 채널.
- <span className='font-medium'>Client interface:</span> 자주 간과되지만, NukeRat 클라이언트 인터페이스는 오래 사용해도 편하도록 세심하게 설계되었습니다.
- <span className='font-medium'>AI Agent:</span> 로컬 모델과 사용자 정의 HTTP 프로바이더를 포함해 AI 모델을 NukeRat에 직접 통합.
