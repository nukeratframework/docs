NukeRat는 API를 통해 외부 AI 모델과 통합을 지원하므로, NukeRat 인터페이스에서 직접 모델과 상호 작용할 수 있습니다.


## 호환성

요청 본문, 헤더 등을 사용자 정의할 수 있으므로 대부분의 모델이 NukeRat 통합 모델과 호환됩니다.

다만 NukeRat는 아래 예처럼 system, user, assistant 역할이 있는 메시지 형식을 사용하는 모델만 지원합니다.

```json
{
    "model": "deepseek-flash",
    "messages": [
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ]
}
```

일부 모델은 다른 명명 규칙을 요구하며, 통합 과정에서 문제가 될 수 있습니다.


## 에이전트 프리셋

모델을 쓰기 위해 반드시 요청을 수동으로 만들 필요는 없습니다. NukeRat에는 **DeepSeek** 프리셋이 포함되어 있습니다. 에이전트 생성 시 유형 **DeepSeek**를 선택하고 API 키를 제공하면 됩니다. 팀 서버는 `deepseek-v4-pro` 모델로 `https://api.deepseek.com/chat/completions`를 호출합니다.

OpenAI, Anthropic처럼 사이버 보안 관련 사용 정책이 엄격한 프로바이더는 통합마다 조정이 달라지므로, 프리셋을 더 추가할 계획은 없습니다.

## 에이전트 생성

에이전트를 만들려면 아래 단계를 따르세요.

  <Steps>
    <Step>
      ### Agents 탭 열기
      **NukeRat** > **Agents**를 연 다음 **New**를 클릭합니다.
    </Step>
    <Step>
      ### 필드 입력
      이름과 에이전트가 저장될 팀 서버를 선택합니다. 수동 HTTP 매핑은 유형 **Custom**, 내장 프리셋은 **DeepSeek**를 선택합니다.
    </Step>
    <Step>
      ### 요청 조정
      이 예에서는 Grok 모델을 사용합니다.

      먼저 Grok 문서의 기본 curl 명령을 가져옵니다.

      ```bash
      curl https://api.x.ai/v1/chat/completions \
        -H "Authorization: Bearer $XAI_API_KEY" \
        -H "Content-Type: application/json" \
        -d '{
            "model": "grok-4.6",
            "messages": [
            {"role": "user", "content": "Hello, Grok!"}
            ]
        }
      ```

      그다음 URL, 본문, 헤더를 에이전트 필드에 매핑합니다. 모습은 다음과 같습니다.
      <ImageZoom src={agentBodyForm} alt="Agent Body Form" className="h-[30rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />

      두 가지를 주목하세요.

      1. 본문 템플릿에 `system` 메시지가 없습니다.
      2. 본문 템플릿에 이미 `user` 메시지가 있습니다.

      이 두 가지 때문에 에이전트 생성이 깨지지는 않습니다. 이유는 다음과 같습니다.

      1. 본문 템플릿에 `system` 메시지가 없으면 NukeRat가 세션 시스템 프롬프트를 `messages` 배열 맨 앞에 삽입합니다.
      2. 본문 템플릿에 이미 있는 메시지는 유지되고, UI의 채팅 턴은 그 뒤에 이어 붙습니다.
    </Step>
    <Step>
      ### 응답 캡처
      요청 응답을 캡처하려면 응답 JSON에서 어떤 키를 사용할지 알아야 합니다.

      가장 쉬운 방법은 curl을 실행해 모델 응답 형식을 확인하는 것입니다.

      Grok 예에서는 응답이 다음과 같습니다.

      ```json
       {
        [... rest of the JSON ...]
        "choices": [{
            "index": 0,
            "message": {
                "role": "assistant",
                "content": "Hello! How can I help you today?",
                "reasoning_content": "The user said: \"Hello, Grok!\"\n",
                "refusal": null
            },
            "finish_reason": "stop"
        }]
        [... rest of the JSON ...]
      }
      ```

      응답을 바탕으로 답이 들어 있는 값까지 JSON 경로를 따라갑니다. 세그먼트마다 점으로 구분하고 필요하면 대괄호 인덱스를 씁니다. 이 경우 `choices[0].message.content`이며 **Response field**에 넣습니다.

      <ImageZoom src={agentResponseKeys} alt="Agent Response Keys" className="h-[5rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />
    </Step>
    <Step>
      ### 에이전트 테스트
      에이전트를 사용하려면 상단 바의 <span className="inline-flex items-center gap-1 whitespace-nowrap align-middle"><Bot size={18.5} className="shrink-0 ml-1.5 mr-1.5" /> 아이콘</span>에서 **AI Agent** 탭을 열거나 **Tabs** > **AI Agent**로 이동합니다.

      **AI Agent** 탭에 대한 자세한 내용은 [AI Agent](/docs/interface/ai-agent)를 참고하세요.

    </Step>
  </Steps>
