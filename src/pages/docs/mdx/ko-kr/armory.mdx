title: Armory

Armory는 543개의 유틸리티(BOF 및 .NET 실행 파일)로 구성된 사전 구성 세트로, 특정 호스트에서 빠르게 다운로드하고 실행할 수 있습니다.

모든 유틸리티는 [**github.com/nukeratframework/armory**](https://github.com/nukeratframework/armory)의 공식 NukeRat armory 저장소에서 다운로드됩니다.

미리 컴파일된 상태로 자동 다운로드되며, 수동으로 빌드할 수도 있습니다. 수동 빌드 방법은 다음과 같습니다.

1. `server/infra/bin/armory/` 폴더에 직접 빌드하여 추가
2. `server/server.conf`의 `[server.armory]` 아래 `repository` 값을 자신의 GitHub 릴리스 호스트를 가리키도록 설정

## 명령

기본적으로 NukeRat에는 미리 컴파일된 armory 바이너리가 포함되어 있지 않습니다. 팀 서버에 설치하려면 armory 명령을 사용하세요.

| 명령 | 동작 |
| --- | --- |
| `armory` | 사용 가능한 유틸리티와 간단한 설명 나열 |
| `armory install all` | 최신 릴리스 번들에서 모든 유틸리티 다운로드 |
| `armory install &lt;tool&gt;` | 한 유틸리티의 파일 다운로드 |
| `armory update` | 저장소에서 armory 인덱스(`armory.json`) 새로 고침 |
| `armory update &lt;tool&gt;` | 인덱스를 새로 고친 뒤 한 유틸리티 재다운로드 |
| `armory remove &lt;tool&gt;` | 해당 유틸리티의 캐시 파일 제거 |
| `help &lt;command&gt;` | 유틸리티 명령 도움말 표시 |
