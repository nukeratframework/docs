title: 커스텀 임플란트

특정 목적을 위해 임플란트를 처음부터 만들어야 할 때가 있습니다. 그런 경우 NukeRat의 임플란트 API를 사용할 수 있습니다.

## 동작 방식

먼저 정리해 두겠습니다. 기본적으로 HTTP 채널에서는 임플란트가 리스너가 관리하는 임플란트 API와 통신합니다. 임플란트가 명령을 가져오고 출력을 다시 보내는 API가 바로 그것입니다.

커스텀 임플란트의 통신 계층을 구현하려면 [임플란트 API](/docs/rest-api/implants) 문서를 참고하세요.

## 예제

아래는 NukeRat 임플란트 API와 통신하는 단순화된 예제입니다. 원본 샘플은 [nukeratframework/api](https://github.com/nukeratframework/api/blob/main/example/implant_example.py) 저장소에 있습니다.

```python
import json
import requests
import urllib3
from implant.aes import build_implant_body

operator_key = ''
aes_key = ''
team_server_url = 'http://192.168.15.21:9000'
implant_listener_url = 'http://192.168.15.21:9090'
listener_response_template = ''

urllib3.disable_warnings()

def implant_example(command):
    """
    Example: create an AES key to communicate with the server and then
    send fingerprinting to the server. This is the process done by the
    implant, the difference is that the AES key is generated during
    compile time.
    """
    global aes_key
    user, password, secret = operator_key.split(':', 2)
    base = team_server_url.rstrip('/')
    token = requests.post(
        f'{base}/auth/login',
        json={'user': user, 'pass': password, 'secret': secret},
        verify=False,
    ).json()['access_token']

    headers = {'Authorization': f'Bearer {token}'}

    if not aes_key:
        aes_key = requests.post(
            f'{base}/api/aes/create',
            json={},
            headers=headers,
            verify=False,
        ).json()['aesKey']

    body = build_implant_body(
        aes_key,
        {
            'option': 'new',
            'tag': 'demo01',
            'ip': '',
            'external_ip': '',
            'hostname': 'fake-fp',
            'user': 'lab',
            'arch': 'x64',
            'pid': 1,
            'os': 'windows',
            'listener': 'http',
            'delay': 2,
            'notes': command,
            'implant_config': {
                'channel': 'http',
                'host': '127.0.0.1',
                'port': '9090',
                'host_tag': 'demo01',
                'delay': 2,
            },
            'metadata': {
                'relays': [],
                'privilege': 'default',
                'internal_ip': '127.0.0.1',
                'host': '127.0.0.1',
                'port': '9090',
            },
        },
    )
    response = requests.post(
        implant_listener_url.rstrip('/') + '/',
        data=body,
        headers={'Content-Type': 'application/octet-stream'},
        verify=False,
    )

    return response.status_code


if __name__ == '__main__':
    print(implant_example('probe'))
```

## 커스텀 채널

기본 HTTP 채널이 아닌 통신 경로가 필요하다면 커스텀 채널 설정이 필요합니다. 동작 방식은 [커스텀 채널](/docs/custom-channels)에서 확인하세요.
