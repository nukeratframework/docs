---
title: AES sync
---

모든 리스너에는 임플란트가 메시지를 암호화할 때 쓰는 통신용 AES 키를 받기 위한 통신 인터페이스가 있습니다. 임플란트를 특정 팀 서버에서 컴파일했을 때, 다른 팀 서버도 그 AES 키를 받아서 임플란트의 통신 메시지를 복호화할 수 있게 하려는 겁니다.

## 동작 방식

임플란트를 컴파일하는 동안, 팀 서버는 설정된 서버 목록을 가져와서 설정된 각 리스너에 그 임플란트의 통신용 AES 키를 담아 요청을 보냅니다.

다만 그 AES 키를 받아서 저장하려면 모든 팀 서버가 같은 AES sync secret key를 가지고 있어야 합니다. 다르면 임플란트는 컴파일된 팀 서버하고만 통신합니다. 메시지를 복호화할 수 있는 곳이 거기뿐이기 때문입니다.

## 설정 방법

1. 팀 서버에서 다음 명령을 사용합니다.

```bash
./nukerat.py server config set server.aes_sync.secret_key 1234567
```

이 같은 명령을 모든 팀 서버에서 실행해야 합니다.

2. 팀 서버 설정 파일에서 설정을 확인합니다.

```bash
./nukerat.py server config list
```

다음과 비슷한 결과가 나와야 합니다.

```toml
[server.aes_sync]
secret_key = 1234567
sync_path = "/sync"
```

3. 팀 서버를 재시작한 뒤, 평소처럼 임플란트 컴파일을 이어갑니다.

## Sync path

AES 키 동기화 경로를 바꿀 수도 있습니다. 그럴 때는 다음 명령을 사용합니다.

```bash
./nukerat.py server config set server.aes_sync.sync_path /example
```

기본 HTTP 채널을 쓸 때, 리스너 URL 주변의 시그니처를 피하는 데 주로 유용합니다.
