---
title: Atajos
---

Atajos de teclado del cliente NukeRat. En macOS, **Ctrl** en estos acordes es **⌘** y **Alt** es **⌥**. Los atajos de fuente del terminal usan siempre la tecla **Ctrl**.

## Espacio de trabajo

| Atajo | Acción |
| --- | --- |
| Alt+T | Abrir un terminal |
| Alt+F | Abrir el explorador de carpetas |
| Alt+R | Abrir procesos |
| Alt+S | Abrir sesiones |
| Alt+A | Abrir el agente de IA |
| Alt+K | Abrir credenciales |
| Alt+1 … Alt+9 | Cambiar a esa pestaña de workspace, si existe |
| Ctrl+Shift+W | Nuevo workspace |
| Shift+Alt+W | Cerrar el workspace actual |
| Ctrl+W | Cerrar el panel bajo el puntero |

## Menú NukeRat

Abren los paneles flotantes de la barra superior.

| Atajo | Acción |
| --- | --- |
| Shift+S | Servers |
| Shift+L | Listeners |
| Shift+I | Implants |
| Shift+N | Network |
| Shift+Q | Queue |
| Shift+E | Logs |

## Vista

| Atajo | Acción |
| --- | --- |
| F11 | Alternar pantalla completa |
| Ctrl++ | Acercar |
| Ctrl+- | Alejar |
| Ctrl+0 | Restablecer el zoom |
| Ctrl+R | Recargar la ventana |
| Ctrl+Shift+I | Alternar las herramientas de desarrollo |

## Aplicación

| Atajo | Acción |
| --- | --- |
| F1 | Abrir la documentación |
| Ctrl+Shift+Q | Salir |
| Escape | Cerrar los menús abiertos. También cierra el panel flotante, salvo que un diálogo dentro de él esté usando Escape |

## Terminal

Pasa el puntero sobre el terminal. **Ctrl** sigue siendo **Ctrl** en todas las plataformas. En macOS, **Alt** del último acorde es **⌥**.

| Atajo | Acción |
| --- | --- |
| Ctrl+scroll arriba | Aumentar el tamaño de la fuente |
| Ctrl+scroll abajo | Reducir el tamaño de la fuente |
| Ctrl+Alt+0 | Restablecer el tamaño de la fuente |
