---
title: REST API
---

El ecosistema NukeRat tiene dos tipos de API:

1. **Implant API**: la usan los implants para enviar y recibir datos del team server. Úsala si planeas construir tu propio implant desde cero.
2. **Team server API**: la usa el cliente NukeRat para gestionar implants y el team server. Úsala si quieres integrar NukeRat con agentes de IA dinámicos o integraciones personalizadas muy específicas.
