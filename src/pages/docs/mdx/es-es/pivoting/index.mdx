---
title: Pivoting
---

Para facilitar el pivoting, NukeRat ofrece tres funciones principales, a saber:

- **Relay**: comunicación entre implants
- **SOCKS**: proxy de red
- **Port forwarding**: redirección de puertos a través de un implant

## Cómo usarlas

Para más información sobre las funciones de pivoting, consulta:

- [Relay](/docs/pivoting/relay)
- [SOCKS](/docs/pivoting/socks)
- [Port forwarding](/docs/pivoting/portforward)
