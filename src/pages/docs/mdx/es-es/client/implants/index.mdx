title: Implantes
---

Los implants son los binarios que se ejecutan en hosts comprometidos. En otros frameworks también se conocen comúnmente como «beacons».

Se pueden crear directamente desde el cliente NukeRat. Para aprender a crear un implant, consulta [Creation](/docs/client/implants/creation).

## Filosofía de diseño del implant

Los implants de NukeRat se construyen en torno a una personalización flexible, lo que te permite crear implants únicos. Esto aplica principalmente a:

- **Creación de implant**: Puedes personalizar cabeceras PE, código preface, PE strings y otras opciones directamente desde el cliente NukeRat.
- **Implant API**: El check-in del implant y el tráfico de tareas usan la [Implant API del listener](/docs/rest-api/implants) (HTTP **POST** cifrado en el canal `endpointPath`), no las rutas REST de gestión del team server bajo `/api/...`.


## Evasión de detección

Los implants de NukeRat incluyen varias técnicas de evasión esenciales para escenarios actuales, siendo indirect syscalls y sleep masking las principales.

La mayoría de las funciones de evasión están ligadas a implants de Windows. Los implants de Linux y macOS admiten actualmente ofuscación de cadenas (Off, Xor o RC4) y las opciones de artefactos PE son solo para Windows.
