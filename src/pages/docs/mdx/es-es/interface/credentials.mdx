La pestaña de credenciales tiene dos propósitos principales:

1. Compartir credenciales entre operadores con más facilidad
2. Adjuntarlas automáticamente a un informe de operación

Puedes abrir la pestaña **Credentials** desde el icono <span className="inline-flex items-center gap-1 whitespace-nowrap align-middle"><KeyRound size={18.5} className="shrink-0 ml-1.5 mr-1.5" /></span> en la barra superior, o desde **Tabs** > **Credentials**.

<ImageZoom src={credentials} alt="Credentials" className="tutorial_img" />

## Cómo usar

Para usar la pestaña de credenciales, sigue estos pasos:

  <Steps>
    <Step>
      ### Añadir una credencial
      Haz clic en el botón **Add** para añadir una nueva credencial.
    </Step>
    <Step>
      ### Rellenar los campos
      Cada credencial está asociada a un host y a un team server, así que ambos deben estar configurados de antemano.
      <ImageZoom src={credentialsAdd} alt="Credentials Add" className="h-[30rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />
    </Step>
    <Step>
      ### Acceder a la credencial
      Tras añadirla, haz doble clic en la fila de la credencial para abrir el panel lateral y ver el texto almacenado.
    </Step>
  </Steps>

Ten en cuenta que la lista de credenciales no exige seleccionar un host o un servidor. Al abrir la pestaña, el cliente ya envía una solicitud a cada team server configurado.
