title: Armory
---

Armory es un conjunto listo para usar de 543 utilidades (BOF y ejecutables .NET) para que puedas descargarlas y ejecutarlas rápidamente en un host concreto.

Todas las utilidades se descargan del repositorio oficial de armory de NukeRat en [**github.com/nukeratframework/armory**](https://github.com/nukeratframework/armory)

Se descargan precompiladas automáticamente, pero también puedes compilarlas manualmente. Para ello puedes:

1. Compilarlas y añadirlas manualmente a la carpeta `server/infra/bin/armory/`
2. Establecer el valor `repository` bajo `[server.armory]` en `server/server.conf` para que apunte a tu propio host de releases de GitHub

## Comandos

Por defecto, NukeRat no incluye binarios de armory precompilados. Usa los comandos de armory para instalarlos en el team server:

| Comando | Acción |
| --- | --- |
| `armory` | Listar utilidades disponibles y descripciones breves |
| `armory install all` | Descargar todas las utilidades del último bundle de release |
| `armory install &lt;tool&gt;` | Descargar archivos de una utilidad |
| `armory update` | Actualizar el índice de armory (`armory.json`) desde el repositorio |
| `armory update &lt;tool&gt;` | Actualizar el índice y volver a descargar una utilidad |
| `armory remove &lt;tool&gt;` | Eliminar archivos en caché de esa utilidad |
| `help &lt;command&gt;` | Mostrar ayuda de un comando de utilidad |
