## Acerca de

NukeRat es un framework de post-explotación orientado a campañas de red team. A modo de comparación, encaja en la misma categoría que Cobalt Strike, Havoc y herramientas similares.

## Propósito

NukeRat nació de la experiencia práctica de un red teamer con otros frameworks del mercado. Sí, ya hay frameworks sólidos, incluidos proyectos de código abierto, pero cada uno sigue teniendo límites que pueden estorbar en el día a día.

Por eso se creó NukeRat: para cubrir huecos que dejan algunas de las opciones actuales y, al mismo tiempo, aportar cosas que se sienten distintas.

Todo ello manteniendo la simplicidad, con *"Make it simple"* como lema central.

## Características

Un resumen rápido de lo que ofrece NukeRat:

- <span className='font-medium'>Armory</span>: Una colección de 543 utilidades listas para usar (BOFs y herramientas .NET) que puedes obtener del repositorio oficial del armory.
- <span className='font-medium'>Evasion:</span> Los implants de Windows incorporan de serie técnicas esenciales para entornos modernos, como indirect syscalls, sleep masks, ofuscación de cadenas y más.
- <span className='font-medium'>Cross platform:</span> De serie, NukeRat soporta Linux y macOS, incluidos sistemas basados en ARM.
- <span className='font-medium'>Custom channels:</span> Canales HTTP y HTTPS con plantillas de cuerpo personalizadas, además de canales totalmente personalizados para plataformas de terceros como Telegram, Dropbox y servicios similares.
- <span className='font-medium'>Client interface:</span> A menudo pasada por alto, la interfaz del cliente de NukeRat se diseñó con cuidado para ser fácil de usar y cómoda en sesiones largas.
- <span className='font-medium'>AI Agent:</span> Integra modelos de IA directamente en NukeRat, incluidos modelos locales y proveedores HTTP personalizados.
