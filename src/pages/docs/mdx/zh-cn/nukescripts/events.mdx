NukeScript 必须设置事件调用，脚本才会运行。因此每个脚本至少应包含一次事件调用。

事件调用格式：`event.<name>:my_function()`

- `event`：保留关键字，表示事件调用开始
- `<name>`：事件名称
- `my_function()`：事件触发时执行的函数

示例：

```python
def on_new_host(row):
    cmd(row["tag"], "whoami")

event.new_host:on_new_host()
```

事件调用的第一个函数称为事件入口函数，须遵守以下语法规则：

1. 入口调用不得传入任何参数
2. 入口函数默认只能有一个参数（名称任意；下文默认使用 `row`）
3. 每条 `event.<name>:handler()` 必须写在脚本末尾，位于其余代码之后

以下为语法错误示例：

```python
def on_new_host(row, some_parameter):
    cmd(row["tag"], "whoami")

event.new_host:on_new_host("example")
```

入口函数的主参数始终收到一个字典，内容为触发事件的数据库行。

要理解字典中有哪些字段，需要了解数据库列布局。详见 [数据库列](#数据库列)。

## 事件目录

可用事件列表：

| 事件 | 说明 | 键 |
| --- | --- | --- |
| `new_host` | 首次签到 | `tag`, `ip`, `external_ip`, `listener`, `arch`, `os`, `user`, `hostname`, `status`, `delay`, `first_seen`, `last_seen`, `next_checkin`, … |
| `removed_host` | 主机已从团队服务器移除 | 与 `new_host` 相同的键 |
| `expired_host` | 主机错过签到窗口 | 与 `new_host` 相同的键 |
| `new_queue_line` | 任务在植入体执行前入队 | `tag`, `host`, `type`, `command`, `input`, `parameters`, `is_completed`, `is_ready`, … |
| `implant_error` | 队列任务失败 | 包含非空 `error` |
| `task_completed` | 队列任务无错误完成 | 以自定义消息完成时含 `is_completed`、`custom_response` |
| `new_checkin` | 新签到 | `tag`, `host`, `type` |
| `keylogger_update` | 键盘记录更新 | `tag`, `content`, `host_tag` |
| `folders_update` | 文件浏览器插入或更新 | `host`, `path`, `type`, `modified`, `size` |
| `process_update` | 进程树插入或更新 | `tag`, `host`, `tree` |
| `output_received` | 新终端输出 | `terminal_id`, `host`, `input`, `output` |
| `credentials_update` | 新存储凭据 | `tag`, `name`, `host`, `content` |
| `listeners_update` | 新 listener 已插入 | `tag`, `type`, `protocol`, `config` |
| `heartbeat_1s` | 每 1 秒运行 | |
| `heartbeat_5s` | 每 5 秒运行 | |
| `heartbeat_10s` | 每 10 秒运行 | |
| `heartbeat_15s` | 每 15 秒运行 | |
| `heartbeat_30s` | 每 30 秒运行 | |
| `heartbeat_1m` | 每 1 分钟运行 | |
| `heartbeat_5m` | 每 5 分钟运行 | |
| `heartbeat_10m` | 每 10 分钟运行 | |
| `heartbeat_15m` | 每 15 分钟运行 | |
| `heartbeat_20m` | 每 20 分钟运行 | |
| `heartbeat_30m` | 每 30 分钟运行 | |
| `heartbeat_60m` | 每 60 分钟运行 | |
| `heartbeat_2h` | 每 2 小时运行 | |
| `heartbeat_12h` | 每 12 小时运行 | |
| `heartbeat_1d` | 每 1 天运行 | |
| `heartbeat_3d` | 每 3 天运行 | |
| `heartbeat_7d` | 每 7 天运行 | |
| `heartbeat_15d` | 每 15 天运行 | |
| `heartbeat_30d` | 每 30 天运行 | |
