title: REST API
---

NukeRat 生态中有两类 API：

1. **Implant API（植入体 API）**：植入体通过它与团队服务器收发数据。若你打算从零编写自己的植入体，需要使用此 API。
2. **Team server API（团队服务器 API）**：NukeRat 客户端通过它管理植入体与团队服务器。适合与动态 AI Agent 或高度定制的集成场景配合使用。
