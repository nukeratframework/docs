## 关于

NukeRat 是一款面向红队行动的后渗透框架，定位与 Cobalt Strike、Havoc 等同类工具相近。

## 目的

NukeRat 源于作者在实战中与其他框架打交道的切身体会。市面上已有不少成熟方案，包括开源项目，但各自仍有一些会在日常使用中拖慢节奏的限制。

因此 NukeRat 意在补全现有工具的一些空白，同时带来若干不同的体验。

一切从简——*「Make it simple」* 是核心理念之一。

## 主要特性

NukeRat 能力概览：

- <span className='font-medium'>Armory（武器库）</span>：官方 Armory 仓库中 543 个即用型工具（BOF 与 .NET），可在客户端直接调用。
- <span className='font-medium'>规避：</span> Windows 植入体内置面向现代环境的常用技术，例如间接系统调用、睡眠掩码、字符串混淆等。
- <span className='font-medium'>跨平台：</span> 开箱支持 Linux 与 macOS，含 ARM 架构。
- <span className='font-medium'>自定义通道：</span> 支持自定义报文模板的 HTTP/HTTPS 通道，以及面向 Telegram、Dropbox 等第三方平台的完全自定义通道。
- <span className='font-medium'>客户端界面：</span> 常被忽视的一点：NukeRat 客户端界面经过精心设计，长时间操作也更顺手。
- <span className='font-medium'>AI Agent：</span> 可将 AI 模型直接接入 NukeRat，包括本地模型与自定义 HTTP 提供商。
