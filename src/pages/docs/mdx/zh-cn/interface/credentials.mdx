凭据标签页主要有两个用途：

1. 便于操作员之间共享凭据
2. 自动关联到行动报告

可从顶部栏<span className="inline-flex items-center gap-1 whitespace-nowrap align-middle">的 <KeyRound size={18.5} className="shrink-0 ml-1.5 mr-1.5" /> 图标</span>打开 **Credentials（凭据）** 标签页，或从 **Tabs（标签页）** > **Credentials（凭据）** 进入。

<ImageZoom src={credentials} alt="Credentials" className="tutorial_img" />

## 使用方法

按以下步骤使用凭据标签页：

  <Steps>
    <Step>
      ### 添加凭据
      点击 **Add（添加）** 添加新凭据。
    </Step>
    <Step>
      ### 填写字段
      每条凭据绑定到特定主机和团队服务器，因此需事先完成相应配置。
      <ImageZoom src={credentialsAdd} alt="Credentials Add" className="h-[30rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />
    </Step>
    <Step>
      ### 查看凭据
      添加后，双击凭据行打开侧栏，即可查看保存的凭据内容。
    </Step>
  </Steps>

凭据列表无需先选择主机或服务器。打开标签页时，客户端会向每个已配置的团队服务器发起请求。
