## 工作原理

植入体枚举正在运行的进程，并将结果转换为客户端可渲染的自定义 JSON 格式。

### Windows

使用 `kernel32.dll`（`CreateToolhelp32Snapshot`、`Process32FirstW`、`Process32NextW`、`OpenProcess`、`QueryFullProcessImageNameW`）与 `iphlpapi.dll`（`GetExtendedTcpTable`）。核心逻辑位于 `implants/windows/stageless/capabilities/process.nim`。

### Linux

读取 `/proc`（`stat`、`status`、`exe`）与 `/proc/net/tcp`。核心逻辑位于 `implants/linux/stageless/capabilities/process.nim`。

### MacOS

使用 `macapi` 模块（`ListProcessIDs`、`ReadProcessStat`、`ReadProcessStatus`、`GetTcpPidMap`）。核心逻辑位于 `implants/mac/stageless/capabilities/process.go`。
