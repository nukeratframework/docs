NukeRat 客户端可同时管理多个团队服务端，在不同服务端上的植入体之间下发命令，无需再开第二个客户端实例。

## 添加团队服务端

在客户端中添加服务器前，需要先准备操作员密钥。创建方式见 [操作员密钥](/docs/operator-key)。

打开 **NukeRat** > **Servers（服务器）**，点击 **Add（添加）**，填写 **New Server（新服务器）** 面板。将操作员密钥粘贴到 **Key (.key)**，或使用 **Upload .key** 从团队服务端目录加载密钥文件。设置 **Protocol（协议）**（http 或 https）、**Host（主机）** 与 **Port（端口）**，然后点击 **Auth（认证）**。

<ImageZoom src={keyAdd} alt="添加密钥" className="h-[30rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />

认证成功后，会为该服务器条目保存 JWT。默认令牌有效期为 7 天；团队服务端通过 `server.keys.jwt.duration` 控制具体时长。详见 [操作员密钥](/docs/operator-key) 中的会话时长说明。

会话过期后，依赖认证的功能会弹出错误 Toast。选中该服务器，打开 **Edit（编辑）**，点击 **Auth** 重新建立会话。编辑模式下可点击 **Clear Session（清除会话）** 删除已存令牌，而不删除服务器条目。

团队服务端机器上的主机、端口、TLS、JWT 时长及 `server.conf` 其余项，请使用 [配置](/docs/configuration) 中的启动器命令进行修改。
