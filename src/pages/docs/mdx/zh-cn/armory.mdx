title: 武器库
---

Armory（武器库）是一套现成的 543 个实用工具（BOF 与 .NET 可执行文件），便于在指定主机上快速下载并运行。

所有工具均来自 NukeRat 官方 Armory 仓库：[**github.com/nukeratframework/armory**](https://github.com/nukeratframework/armory)

预编译二进制会自动下载，也可手动构建：

1. 自行构建并放入 `server/infra/bin/armory/` 目录
2. 在 `server/server.conf` 的 `[server.armory]` 中将 `repository` 指向你自己的 GitHub Release 源

## 命令

默认情况下，NukeRat 不包含预编译的 Armory 二进制。在 team server 上使用 armory 命令安装：

| 命令 | 作用 |
| --- | --- |
| `armory` | 列出可用工具及简要说明 |
| `armory install all` | 从最新 release 包下载全部工具 |
| `armory install &lt;tool&gt;` | 下载单个工具的文件 |
| `armory update` | 从仓库刷新 Armory 索引（`armory.json`） |
| `armory update &lt;tool&gt;` | 刷新索引并重新下载单个工具 |
| `armory remove &lt;tool&gt;` | 删除该工具的缓存文件 |
| `help &lt;command&gt;` | 显示某工具命令的帮助 |
