---
title: 快捷键
---

NukeRat 客户端的键盘快捷键。在 macOS 上，这些组合里的 **Ctrl** 是 **⌘**，**Alt** 是 **⌥**。终端字号快捷键始终使用 **Ctrl** 键。

## 工作区

| 快捷键 | 动作 |
| --- | --- |
| Alt+T | 打开终端 |
| Alt+F | 打开文件夹浏览器 |
| Alt+R | 打开进程 |
| Alt+S | 打开会话 |
| Alt+A | 打开 AI Agent |
| Alt+K | 打开凭据 |
| Alt+1 … Alt+9 | 切换到对应的工作区标签（该标签存在时） |
| Ctrl+Shift+W | 新建工作区 |
| Shift+Alt+W | 关闭当前工作区 |
| Ctrl+W | 关闭指针下的面板 |

## NukeRat 菜单

打开顶栏上的浮动面板。

| 快捷键 | 动作 |
| --- | --- |
| Shift+S | 服务端 |
| Shift+L | 监听器 |
| Shift+I | 植入体 |
| Shift+N | 网络 |
| Shift+Q | 队列 |
| Shift+E | 日志 |

## 视图

| 快捷键 | 动作 |
| --- | --- |
| F11 | 切换全屏 |
| Ctrl++ | 放大 |
| Ctrl+- | 缩小 |
| Ctrl+0 | 重置缩放 |
| Ctrl+R | 重新加载窗口 |
| Ctrl+Shift+I | 切换开发者工具 |

## 应用

| 快捷键 | 动作 |
| --- | --- |
| F1 | 打开文档 |
| Ctrl+Shift+Q | 退出 |
| Escape | 关闭已打开的菜单。同时关闭浮动面板；如果面板里的对话框正在使用 Escape，则不关闭面板 |

## 终端

把指针放在终端上。**Ctrl** 在所有平台上都是 **Ctrl**。在 macOS 上，最后一条组合里的 **Alt** 是 **⌥**。

| 快捷键 | 动作 |
| --- | --- |
| Ctrl+向上滚动 | 增大字号 |
| Ctrl+向下滚动 | 减小字号 |
| Ctrl+Alt+0 | 重置字号 |
