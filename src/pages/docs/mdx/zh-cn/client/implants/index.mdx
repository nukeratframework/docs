---
title: 植入体
---

植入体是在已控主机上运行的程序。在其他框架中，也常被称为「beacon」。

可直接通过 NukeRat 客户端创建。创建步骤见 [Creation（创建）](/docs/client/implants/creation)。

## 植入体设计理念

NukeRat 植入体强调灵活定制，便于打造独一无二的样本。主要体现在：

- **植入体创建**：可在 NukeRat 客户端中自定义 PE 头、preface 代码、PE 字符串等选项。
- **植入体 API**：植入体签到与任务流量走 [listener 植入体 API](/docs/rest-api/implants)（在通道 `endpointPath` 上的加密 HTTP **POST**），而非 team server 管理 REST 路由 `/api/...`。


## 检测规避

NukeRat 植入体包含多种面向现代场景的规避技术，其中间接系统调用与 sleep masking 是核心能力。

多数规避功能针对 Windows 植入体。Linux 与 macOS 植入体目前支持字符串混淆（Off、Xor 或 RC4）；PE artifact 选项仅 Windows 可用。

## 功能

NukeRat 植入体包含许多当前场景所需的能力。下面是 Windows 植入体命令参考（在会话中运行 `help` 可查看实时列表）。平台相关命令请用 `help -os linux` 或 `help -os mac`。
