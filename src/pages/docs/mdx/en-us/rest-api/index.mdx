title: Rest API
---

The NukeRat ecosystem has two types of APIs:

1. **Implant API**: implants use this to send and receive data from the team server. Use it if you plan to build your own implant from scratch.
2. **Team server API**: the NukeRat client uses this to manage implants and the team server. Use it if you want to integrate NukeRat with dynamic AI agents or very specific custom integrations.

## Documentation

To read more about the APIs, see:

- [Implant API](/docs/rest-api/implants)
- [Team server API](/docs/rest-api/team-server)
