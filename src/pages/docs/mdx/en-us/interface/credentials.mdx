The credentials tab serves two main purposes:

1. Share credentials between operators more easily
2. Attach them automatically to an operation report

You can open the **Credentials** tab from <span className="inline-flex items-center gap-1 whitespace-nowrap align-middle">the <KeyRound size={18.5} className="shrink-0 ml-1.5 mr-1.5" /> icon</span> in the top bar, or from **Tabs** > **Credentials**.

<ImageZoom src={credentials} alt="Credentials" className="tutorial_img" />

## How to use

To use the credentials tab, follow these steps:

  <Steps>
    <Step>
      ### Add a credential
      Click the **Add** button to add a new credential.
    </Step>
    <Step>
      ### Fill in the fields
      Each credential is tied to a host and a team server, so both must be configured beforehand.
      <ImageZoom src={credentialsAdd} alt="Credentials Add" className="h-[30rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />
    </Step>
    <Step>
      ### Access the credential
      After adding it, double click the credential row to open the side panel and view the stored credential text.
    </Step>
  </Steps>

Note that the credentials list does not require selecting a host or server. When you open the tab, the client already sends a request to every configured team server.
