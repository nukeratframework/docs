## About

NukeRat is a post exploitation framework focused on red team campaigns. For comparison, it sits in the same category as Cobalt Strike, Havoc, and similar tools.

## Purpose

NukeRat came from one red teamer's hands on experience with other frameworks on the market. Yes, we already have strong frameworks out there, including open source projects, but each one still has limits that can get in the way day to day.

So NukeRat was built to fill gaps left by some of what we have today, and at the same time bring a few things that feel different.

All of that while keeping things simple, with *"Make it simple"* as a core motto.

## Features

A quick summary of what NukeRat offers:

- <span className='font-medium'>Armory</span>: A collection of 543 ready to use utilities (BOFs and .NET tools) you can pull from the official armory repository.
- <span className='font-medium'>Evasion:</span> Windows implants ship with essential techniques for modern environments built in, such as indirect syscalls, sleep masks, string obfuscation, and more.
- <span className='font-medium'>Cross platform:</span> Out of the box, NukeRat supports Linux and macOS, including ARM based systems.
- <span className='font-medium'>Custom channels:</span> HTTP and HTTPS channels with custom body templates, plus fully custom channels for third party platforms like Telegram, Dropbox, and similar services.
- <span className='font-medium'>Client interface:</span> Often overlooked, NukeRat's client interface was carefully designed to be easy to use and comfortable for long sessions.
- <span className='font-medium'>AI Agent:</span> Integrate AI models directly into NukeRat, including local models and custom HTTP providers.
