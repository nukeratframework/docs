---
title: Listeners
---

In NukeRat, a listener is any service or routine that actively listens on a port.

Listener types include:

- **Channel**: communication channel used by implants to receive commands and send output.
- **File Server**: file server used to host files or serve simple applications.
- **AES sync**: AES sync listener.

## How to create

Open **NukeRat** > [Listeners](/docs/listeners) > **Add** and choose the type:

- **Listeners**
  - [Channel](/docs/listeners/channel)
  - [File Server](/docs/listeners/file-server)
  - [AES sync](/docs/listeners/aes-sync)
