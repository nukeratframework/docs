---
title: Shortcuts
---

Keyboard shortcuts for the NukeRat client. On macOS, **Ctrl** in these chords is **⌘** and **Alt** is **⌥**. The terminal font shortcuts always use the **Ctrl** key.

## Workspace

| Shortcut | Action |
| --- | --- |
| Alt+T | Open a terminal |
| Alt+F | Open the folder explorer |
| Alt+R | Open processes |
| Alt+S | Open sessions |
| Alt+A | Open the AI agent |
| Alt+K | Open credentials |
| Alt+1 … Alt+9 | Switch to that workspace tab, when it exists |
| Ctrl+Shift+W | New workspace |
| Shift+Alt+W | Close the current workspace |
| Ctrl+W | Close the panel under the pointer |

## NukeRat menu

These open the floating panels from the top bar.

| Shortcut | Action |
| --- | --- |
| Shift+S | Servers |
| Shift+L | Listeners |
| Shift+I | Implants |
| Shift+N | Network |
| Shift+Q | Queue |
| Shift+E | Logs |

## View

| Shortcut | Action |
| --- | --- |
| F11 | Toggle fullscreen |
| Ctrl++ | Zoom in |
| Ctrl+- | Zoom out |
| Ctrl+0 | Reset zoom |
| Ctrl+R | Reload the window |
| Ctrl+Shift+I | Toggle developer tools |

## Application

| Shortcut | Action |
| --- | --- |
| F1 | Open the documentation |
| Ctrl+Shift+Q | Quit |
| Escape | Close open menus. Also closes the floating panel, unless a dialog inside it is using Escape |

## Terminal

Hover the terminal. **Ctrl** stays **Ctrl** on every platform. On macOS, **Alt** in the last chord is **⌥**.

| Shortcut | Action |
| --- | --- |
| Ctrl+scroll up | Increase the font size |
| Ctrl+scroll down | Decrease the font size |
| Ctrl+Alt+0 | Reset the font size |
