---
title: Pivoting
---

To help with the pivoting process, NukeRat provides three core features, namely:

- **Relay**: communication between implants
- **SOCKS**: network proxy
- **Port forwarding**: port redirection through an implant

## How to use

To read more about pivoting features, see:

- [Relay](/docs/pivoting/relay)
- [SOCKS](/docs/pivoting/socks)
- [Port forwarding](/docs/pivoting/portforward)
