title: Armory
---

Armory is a ready made set of 543 utilities (BOFs and .NET executables) so you can download and run them quickly on a specific host.

All utilities are downloaded from the official NukeRat armory repository at [**github.com/nukeratframework/armory**](https://github.com/nukeratframework/armory)

They are downloaded precompiled automatically, but you can also build them manually. To do that, you can:

1. Build and add them manually to the `server/infra/bin/armory/` folder
2. Set the `repository` value under `[server.armory]` in `server/server.conf` to point at your own GitHub release host

## Commands

By default, NukeRat does not ship with precompiled armory binaries. Use the armory commands to install them on the team server:

| Command | Action |
| --- | --- |
| `armory` | List available utilities and short descriptions |
| `armory install all` | Download all utilities from the latest release bundle |
| `armory install &lt;tool&gt;` | Download files for one utility |
| `armory update` | Refresh the armory index (`armory.json`) from the repository |
| `armory update &lt;tool&gt;` | Refresh the index and re-download one utility |
| `armory remove &lt;tool&gt;` | Remove cached files for that utility |
| `help &lt;command&gt;` | Show help for a utility command |
