The NukeRat client is the operator interface for one or more team servers. After you connect and authenticate servers, use the top bar and the **NukeRat** menu to manage listeners, implants, and operations.

## Getting started

1. Add team servers and authenticate with an operator key. See [Servers](/docs/servers).
2. Create operator keys on the team server. See [Operator key](/docs/operator-key) in the Server section of the docs.
