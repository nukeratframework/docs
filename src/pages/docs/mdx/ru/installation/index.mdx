Ниже — команды для установки клиента и сервера NukeRat. Сервер работает только на **Linux**. Клиент — на **Windows**, **Linux** и **macOS**.

<Callout
  type="info"
  title="Подсказка"

>
  Если вы впервые работаете с NukeRat, откройте [Быстрая настройка](/docs/fast-setup) — там за несколько шагов описано, как получить первый рабочий имплант.
</Callout>

## Команды

  <Tabs items={['Linux', 'Windows', 'macOS']} groupId="installation-os" persist>
    <Tab value="Linux">
      **Сервер:**
      ```bash
      git clone https://github.com/nukeratframework/nukerat && cd nukerat && sudo bash install.sh server
      ```

      **Клиент:**
      ```bash
      git clone https://github.com/nukeratframework/nukerat && cd nukerat && sudo bash install.sh client
      ```

      **Оба компонента:**
      ```bash
      git clone https://github.com/nukeratframework/nukerat && cd nukerat && sudo bash install.sh all
      ```
    </Tab>
    <Tab value="Windows">
      **Клиент:**
      ```bash
      git clone https://github.com/nukeratframework/nukerat && cd nukerat && install\windows.bat client
      ```
    </Tab>
    <Tab value="macOS">
      **Клиент:**
      ```bash
      git clone https://github.com/nukeratframework/nukerat && cd nukerat && bash install/mac.sh client
      ```
    </Tab>
  </Tabs>
