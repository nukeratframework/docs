---
title: Ключ оператора
---

Ключ оператора — ключ аутентификации для входа и создания сессии доступа на сервере команды.

На хосте сервера команды выполните:

```bash
nukerat server key add bill
```

Ключ выводится в консоль, а в каталоге, из которого выполнена команда, создаётся файл `.key`.

Чтобы вывести список всех сгенерированных ключей:

```bash
nukerat server key list
```

Чтобы удалить ключ:

```bash
nukerat server key rem bill
```

## Структура ключа

```
bill:1pDi0uSLlFKfCjjHPL9uZAlP:1789429491513043059V5Kua8T5ug3ZHcVt…
```

Ключ оператора состоит из трёх частей, разделённых двоеточиями:

1. Имя оператора (только для идентификации)
2. Пароль (на сервере проверяется через bcrypt)
3. Секрет

При использовании ключа клиент отправляет `user`, `pass` и `secret` в POST-запросе на `/auth/login`, чтобы получить JWT сессии.

## Длительность сессии

По умолчанию JWT-сессия действительна 7 дней (`server.keys.jwt.duration` в конфигурации сервера, значение по умолчанию — `7d`). После истечения срока при попытке использовать функции, требующие аутентификации, появится toast с ошибкой.

Чтобы продлить сессию, войдите снова с сохранённым ключом.
