---
title: Сочетания клавиш
---

Сочетания клавиш клиента NukeRat. На macOS **Ctrl** в этих сочетаниях — это **⌘**, а **Alt** — **⌥**. Сочетания размера шрифта терминала всегда используют клавишу **Ctrl**.

## Рабочая область

| Сочетание | Действие |
| --- | --- |
| Alt+T | Открыть терминал |
| Alt+F | Открыть проводник |
| Alt+R | Открыть процессы |
| Alt+S | Открыть сессии |
| Alt+A | Открыть AI-агента |
| Alt+K | Открыть учётные данные |
| Alt+1 … Alt+9 | Перейти на вкладку рабочей области с этим номером, если она есть |
| Ctrl+Shift+W | Новая рабочая область |
| Shift+Alt+W | Закрыть текущую рабочую область |
| Ctrl+W | Закрыть панель под указателем |

## Меню NukeRat

Открывают плавающие панели верхней панели.

| Сочетание | Действие |
| --- | --- |
| Shift+S | Servers |
| Shift+L | Listeners |
| Shift+I | Implants |
| Shift+N | Network |
| Shift+Q | Queue |
| Shift+E | Logs |

## Вид

| Сочетание | Действие |
| --- | --- |
| F11 | Переключить полный экран |
| Ctrl++ | Увеличить |
| Ctrl+- | Уменьшить |
| Ctrl+0 | Сбросить масштаб |
| Ctrl+R | Перезагрузить окно |
| Ctrl+Shift+I | Переключить инструменты разработчика |

## Приложение

| Сочетание | Действие |
| --- | --- |
| F1 | Открыть документацию |
| Ctrl+Shift+Q | Выйти |
| Escape | Закрыть открытые меню. Также закрывает плавающую панель, если диалог внутри неё не занимает Escape |

## Терминал

Наведите указатель на терминал. **Ctrl** остаётся **Ctrl** на всех платформах. На macOS **Alt** в последнем сочетании — это **⌥**.

| Сочетание | Действие |
| --- | --- |
| Ctrl+прокрутка вверх | Увеличить размер шрифта |
| Ctrl+прокрутка вниз | Уменьшить размер шрифта |
| Ctrl+Alt+0 | Сбросить размер шрифта |
