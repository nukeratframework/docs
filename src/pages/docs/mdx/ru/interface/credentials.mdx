Вкладка **Credentials** решает две задачи:

1. Упростить обмен учётными данными между операторами
2. Автоматически включать их в отчёт об операции

Вкладку можно открыть через значок <span className="inline-flex items-center gap-1 whitespace-nowrap align-middle"><KeyRound size={18.5} className="shrink-0 ml-1.5 mr-1.5" /></span> на верхней панели или **Tabs** > **Credentials**.

<ImageZoom src={credentials} alt="Credentials" className="tutorial_img" />

## Как пользоваться

  <Steps>
    <Step>
      ### Добавьте учётные данные
      Нажмите **Add**, чтобы добавить новую запись.
    </Step>
    <Step>
      ### Заполните поля
      Каждая запись привязана к хосту и team server — оба нужно настроить заранее.
      <ImageZoom src={credentialsAdd} alt="Credentials Add" className="h-[30rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />
    </Step>
    <Step>
      ### Просмотр записи
      После добавления дважды щёлкните по строке — на боковой панели откроется сохранённый текст учётных данных.
    </Step>
  </Steps>

Список учётных данных не требует предварительного выбора хоста или сервера: при открытии вкладки клиент уже запрашивает данные у всех настроенных team server.
