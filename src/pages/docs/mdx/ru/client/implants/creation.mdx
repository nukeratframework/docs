Здесь — создание имплантов в клиенте NukeRat. Две базы: **Stageless** и **Loader**.

- **Stageless**: полный имплант с подключением к listener по HTTP, HTTPS, custom HTTP, TCP или SMB (SMB только Windows)
- **Loader**: минимальный имплант, загружающий внешнюю стадию по заданному URL
- **Relay stageless** (конфигурация): stageless с pivot-каналами (**TCP** везде, **SMB** в Windows), связь через другой имплант, а не напрямую с team server

    <Step>

## Relay stageless-имплант

База по-прежнему **Stageless**. В C2 в **Channel** выберите pivot (**TCP** или **SMB** в Windows). В **Relay implant** укажите upstream (хост, порт или SMB pipe) для трафика к team server.

Удобно, когда у цели нет исходящего доступа в интернет.

Шаги как у stageless, меняется только C2.

<ImageZoom src={relayImplant} alt="Relay Implant" className="h-[18rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />

**TCP** — все поддерживаемые ОС. **SMB** — только Windows. На цели relay уже должен быть на upstream. Подробнее — [Relay](/docs/pivoting/relay#how-to-use).
