В ходе операции полезно понимать, что происходит. В NukeRat для этого есть две возможности — без необходимости заходить на сервер команды и вручную разбирать логи.

## Очередь команд

Откройте **NukeRat** > **Queue**, чтобы увидеть все команды в очереди выполнения. В таблице — ожидающие и уже выполненные команды. Это помогает:

- удалить команды, добавленные по ошибке (до того как имплант их получит)
- посмотреть вывод команд из закрытой вкладки терминала
- выяснить, из-за какой ошибки команда не выполнилась

<ImageZoom src={commandQueue} alt="Command queue" className="h-[30rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />

Команды в таблице относятся не только к вкладке терминала — туда же попадает активность из обозревателя файлов и вкладки процессов.

Двойной щелчок по строке показывает все детали события очереди.

Команду можно удалить из очереди: выделите её и нажмите **Delete**. Запись удалится из базы, и имплант не выполнит команду, если она ещё не была доставлена.

## Журнал событий

Откройте **NukeRat** > **Event Log**, чтобы просмотреть логи выбранного сервера команды. Записи сгруппированы так:

- **Listeners**: трафик и действия на HTTP-каналах и file server listener (из `listeners.log`)
- **Launcher**: сообщения при запуске сервера и launcher (из `server.log`)
- **Server**: ошибки и информационные сообщения API и ядра сервера команды (из `server.log`)

Представление Event Log читает `server.log` и `listeners.log` через endpoint сервера команды [`GET /api/logs/`](/docs/rest-api/team-server).
