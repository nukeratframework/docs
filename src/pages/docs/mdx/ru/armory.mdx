Armory — готовый набор из 543 утилит (BOF и .NET-исполняемые файлы) для быстрой загрузки и запуска на целевом хосте.

Все утилиты берутся из официального репозитория armory NukeRat: [**github.com/nukeratframework/armory**](https://github.com/nukeratframework/armory)

Предкомпилированные бинарники подтягиваются автоматически, но их можно собрать вручную:

1. Соберите утилиты и положите в каталог `server/infra/bin/armory/`
2. В `server/server.conf` в секции `[server.armory]` задайте `repository` на свой GitHub release

## Команды

По умолчанию NukeRat не включает предсобранные бинарники armory. Установите их на team server командами armory:

| Команда | Действие |
| --- | --- |
| `armory` | Список утилит и кратких описаний |
| `armory install all` | Загрузить все утилиты из последнего release |
| `armory install &lt;tool&gt;` | Загрузить файлы одной утилиты |
| `armory update` | Обновить индекс armory (`armory.json`) из репозитория |
| `armory update &lt;tool&gt;` | Обновить индекс и перекачать одну утилиту |
| `armory remove &lt;tool&gt;` | Удалить кэш утилиты |
| `help &lt;command&gt;` | Справка по команде утилиты |
