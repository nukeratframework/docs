title: Справочник REST API
---

В экосистеме NukeRat есть два типа API:

1. **Implant API** — импланты используют его для отправки и получения данных с team server. Нужен, если вы собираетесь писать свой имплант с нуля.
2. **Team server API** — клиент NukeRat использует его для управления имплантами и team server. Подходит для интеграции с динамическими AI-агентами или узкоспециализированными сценариями.

## Документация

Подробнее об API:

- [Implant API](/docs/rest-api/implants) — API импланта
- [Team server API](/docs/rest-api/team-server) — API сервера команды
