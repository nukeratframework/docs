---
title: Пивотинг
---

Для pivoting в NukeRat есть три базовые возможности:

- **Relay**: связь между имплантами
- **SOCKS**: сетевой прокси
- **Port forwarding**: перенаправление портов через имплант

## Как пользоваться

Подробнее о возможностях pivoting:
