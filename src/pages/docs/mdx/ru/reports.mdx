NukeRat позволяет формировать отчёты обо всём, что произошло в операции. Каждый отчёт можно экспортировать в PDF (по умолчанию), HTML или JSON. Доступны такие типы:

- **Activity**: выполненные команды терминала и захваченные учётные данные
- **Hosts Report**: сведения о скомпрометированных хостах
- **Indicators of Compromise**: список индикаторов компрометации (IoC)

## Отчёт об активности

Отчёты об активности дают обзор операции на высоком уровне. Структура такая:

| Раздел | Описание |
|---------|-------------|
| Target scope | Список скомпрометированных хостов |
| Queue activity | До 200 команд терминала (время, hostname, пользователь, команда) |
| Captured credentials | До 200 захваченных учётных записей |

При создании отчёта об активности можно включить **Hide credentials**, чтобы замаскировать содержимое учётных данных в экспорте.

<Callout type="info">
  Подсказка: строки queue activity берутся из записей очереди терминала. Нежелательные команды можно убрать в **NukeRat** > **Queue** — до генерации отчёта.
</Callout>

## Отчёт по хостам

Самый простой отчёт: одна таблица до 200 скомпрометированных хостов с полями:

- Hostname
- User
- Operating system
- Internal IP
- External IP
- PID импланта NukeRat

## Indicators of Compromise

Отчёт IoC — самый подробный из трёх. В нём все IoC операции по разделам:

| Раздел | Описание |
|---------|-------------|
| Target scope | Список скомпрометированных хостов |
| IP Addresses | Список IP-адресов |
| Domains | Список доменов |
| Files | Пути к файлам, найденные в выводе команд |
| Hashes | Хеши файлов (MD5, SHA1 и SHA256) |

Базу IoC NukeRat заполняет автоматически. Вывод команд терминала сканируется правилами regex на IPv4, домены и известные расширения файлов. Для файлов, переданных через file server, сохраняются MD5, SHA1 и SHA256. За кулисами не работает ничего динамического вроде моделей ИИ, обрабатывающих вывод, поэтому возможны ложные индикаторы или ошибки захвата, хотя это случается нечасто.

<Callout type="info">
  Подсказка: чтобы исправить проблемы с захватом индикаторов, в NukeRat есть редактор IoC — просмотр и удаление записей. Откройте **NukeRat** > **IOCs**.
</Callout>

## Ограничения

Все отчёты формируются на выбранном сервере команды. Каждый отчёт охватывает только хосты, подключённые к этому серверу.

Если используется несколько серверов команды, отчёт нужно генерировать отдельно для каждого.

## Обратная связь

Генерация отчётов пока экспериментальная. Она может меняться чаще, чем большинство других возможностей NukeRat — в основном потому, что мы ещё выясняем, что операторам действительно нужно от отчётов.

Если есть отзывы или предложения, создайте issue на GitHub.
