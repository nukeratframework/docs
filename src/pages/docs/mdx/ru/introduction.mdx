## О проекте

NukeRat — фреймворк постэксплуатации для операций red team. По классу решений он близок к Cobalt Strike, Havoc и аналогичным инструментам.

## Зачем он нужен

NukeRat вырос из практического опыта одного red team-специалиста с другими фреймворками на рынке. Сильные решения уже есть, в том числе с открытым исходным кодом, но у каждого остаются ограничения, которые мешают в ежедневной работе.

Поэтому NukeRat закрывает пробелы существующих инструментов и добавляет несколько собственных идей.

При этом акцент — на простоте; один из принципов проекта: *«Make it simple»*.

## Возможности

Кратко о том, что даёт NukeRat:

- <span className='font-medium'>Armory</span>: коллекция из 543 готовых утилит (BOF и .NET-инструменты) из официального репозитория armory.
- <span className='font-medium'>Evasion:</span> Windows-импланты из коробки включают техники для современных сред: indirect syscalls, sleep mask, обфускация строк и др.
- <span className='font-medium'>Cross platform:</span> из коробки поддерживаются Linux и macOS, в том числе на ARM.
- <span className='font-medium'>Custom channels:</span> HTTP/HTTPS с настраиваемыми шаблонами тела запроса и полностью кастомные каналы через сторонние платформы — Telegram, Dropbox и т. п.
- <span className='font-medium'>Client interface:</span> клиентский интерфейс спроектирован так, чтобы им было удобно пользоваться часами подряд — деталь, которую часто упускают.
- <span className='font-medium'>AI Agent:</span> интеграция моделей ИИ прямо в NukeRat — локальные модели и произвольные HTTP-провайдеры.
