Клиент NukeRat может одновременно работать с несколькими серверами команды. Команды для имплантов на разных серверах выполняются из одного экземпляра клиента.

## Добавление сервера команды

Чтобы настроить сервер в клиенте NukeRat, нужен ключ оператора. Как его создать — в разделе [Ключ оператора](/docs/operator-key).

Откройте **NukeRat** > **Servers**, нажмите **Add** и заполните панель **New Server**. Вставьте ключ в **Key (.key)** или загрузите файл через **Upload .key** из каталога сервера команды. Укажите **Protocol** (http или https), **Host** и **Port**, затем **Auth**.

<ImageZoom src={keyAdd} alt="Добавление ключа" className="h-[30rem] tutorial_img" style={{ marginLeft: 0, marginRight: 0, display: 'block' }} />

После успешной аутентификации для записи сервера сохраняется JWT. По умолчанию токен действует 7 дней. Точный срок задаёт сервер команды параметром `server.keys.jwt.duration`. Подробнее — в разделе о длительности сессии в [Ключ оператора](/docs/operator-key).

Когда сессия истекает, функции, требующие аутентификации, показывают toast с ошибкой. Выберите сервер, откройте **Edit** и нажмите **Auth**, чтобы начать новую сессию. В режиме редактирования **Clear Session** удаляет сохранённый токен, не удаляя запись о сервере.

Хост, порт, TLS, срок JWT и остальные параметры `server.conf` на машине сервера команды настраиваются командами лаунчера из [Конфигурация](/docs/servers/configuration).
