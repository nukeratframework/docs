|----------|--------------|
| English | [en-us](https://nukerat.com/docs) |
| Spanish | [es-es](https://nukerat.com/docs?lang=es-es) |
| Korean | [ko-kr](https://nukerat.com/docs?lang=ko-kr) |
| Chinese (Simplified) | [zh-cn](https://nukerat.com/docs?lang=zh-cn) |

| Persian | [fa-ir](https://nukerat.com/docs?lang=fa-ir) |
| Japanese | [ja-jp](https://nukerat.com/docs?lang=ja-jp) |

## Usage

To run a local version of the documentation, use:

```
npm run build
```

Then run:

```
npm run preview
```

## Contributing

Many of the documentation languages were translated with AI models and may contain translation errors or a loss of context. Feel free to help us improve the documentation if you find a problem.
